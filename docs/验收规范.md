# 最小实现与实验验收规范

版本：2026-10-12，protein开发评价协议v1。规范模型：[研究方案 §3](研究方案.md)的有限候选多核岭回归。这里的数值阈值、网格与停止规则均为**设计选择**，不是已证明最优参数。目标是使一个实现版本可以被独立检查，不要求先完成大型神经网络复现。

## 1. 执行目标、上下文与边界

**目标：** 实现 M0/M1/M2/MU 和能区分功能先验贡献的最小对照；首先核验输入、特征与求解是否一致，再评价公开开发分区的连续性状。必要上下文是[研究方案](研究方案.md)的数学定义、[唯一配置](../configs/funcprior.toml)和既有划分。文献来源的待核对事项见[验收记录](验收记录.md)。

**实施要求：** 使用可测试的线性代数与模拟教师验证实现，实际材料与教师另行验收。只读取许可开发表型，保留既定划分；封存值禁止读取。未知性状含义、参考版本和相位须查明，历史分数不能作为本轮结果。

**验收状态记录规则：** `ALGEBRA_VERIFIED`、`TEACHER_INTERFACE_VERIFIED`、`DATA_READY`、`DEVELOPMENT_EVALUATED` 分别记录，前一状态不自动证明后一状态。实际实现与验收状态见[验收记录](验收记录.md)。最终交付物必须同时包含预测、配置、版本、耗时和失败记录。

## 2. 输入输出要求

### 2.1 必填输入

|输入|最少字段／形状|失败处理|
|---|---|---|
|`samples.tsv`|唯一 `sample_id`、`group_id`、可选 `population`|重复 ID、组跨分区直接报错|
|`variants.tsv`|唯一 `variant_id`、chr、1\-based pos、REF、ALT、reference\_build|限双等位 SNP；REF 与 FASTA 不符直接报错，不自动翻转|
|剂量矩阵|n×M，0/1/2，缺失用明确数值编码；附样本与位点顺序哈希|非法值、顺序不一致直接报错|
|可选可信相位|n×M×2 的0/1等位状态及相位有效掩码|与剂量和不一致直接报错；不得任意补相位|
|`regions.bed`|外部 ACR 区域 ID、chr、0\-based半开区间、来源与版本|未落实则停止真实功能分支；不以全数据 GWAS 替代|
|FASTA|当前数据版本对应的参考序列和校验和；本版 SoyBase 为 Wm82.gnm2.DTC4|缺文件则停止序列构造，不重新解释坐标|
|`splits.tsv`|开发材料、外层 fold、内层 fold、组 ID；封存 ID 只作禁止访问清单|保留原始划分；不能因分数差重新随机|
|`phenotype_development.tsv`|sample\_id、预先指定 trait\_id、value、unit、censor\_status|只加载开发表；删失／非发芽／缺失含义不明则停止真实性状训练|
|`teacher_manifest.json`|仓库与代码 commit、权重 revision及SHA256、tokenizer、label映射、长度、dtype|任一关键字段未知不可声称教师复现完成|

既有队列保留原发现／封存划分，不另划或默认无封存；本项目官方重建的新队列按用户授权建立独立版本的开发／封存与组约束划分，确定后不得改写，要求与清单见[任务书](任务书.md)。实现若当前只有合并的全体表型文件，须由合格隔离接口提供开发表；不得先把全表载入内存再过滤封存 ID。读取日志记录访问路径和允许样本集合，不记录封存值。

主性状 `primary_trait_id` 必填，不赋任意默认值。本项目目标必须在查看本轮预测前写入配置。若无已确定目标，程序只做无表型验证，返回 `TARGET_UNSPECIFIED`。

### 2.2 配置与预算

实验参数的唯一来源是 [`configs/funcprior.toml`](../configs/funcprior.toml)，本规范不维护另一份默认配置。配置对应 SoyBase protein 任务，物种参考、固定目录多 SNP 候选规则、训练预算及既有十折外层安排见[任务书](任务书.md)。本规范定义当前大豆实验的计算要求；配置填写完成不代表输入已通过验收。

预算是首轮上限，实际硬件与速度必须实测；不以用户历史机器规格推定当前可用资源。64条推理包含参考、单变异、多变异各类；重复一遍验证缓存与确定性。若投影超限，返回成本表并停止扩大，不按教师分数或表型临时选择“便宜又有效”的窗口。调整上限或窗口数需新配置版本。

内外层折数及一致性判据读取当前版本配置，并核验实际固定清单；本版 SoyBase 为开发集组约束十折外层、各训练预算四折内层。少于规定折数的独立组不能称为完成相应验证。连续响应中的真实极值不能自动视为删失或截尾处理。

### 2.3 每次训练的输出

保存：`config.json`、`input_manifest.json`、`teacher_manifest.json`、`fold_manifest.json`、`variant_qc.tsv`、`region_validity.tsv`、`feature_cache_manifest.jsonl`、`kernel_diagnostics.json`、`inner_scores.tsv`、`selected_model.json`、`predictions.parquet`、`metrics.json`、`timing.json`、`tests.json`、`run_status.json`。格式可用等价 TSV/JSON 替换 parquet，但字段不能缺省。

逐材料预测至少含 `sample_id, trait_id, outer_fold, model_family, train_ids_hash, config_hash, y_observed, y_predicted, train_y_mean, valid_region_fraction`。无权读取表型的推理阶段不输出 `y_observed`，由开发评价接口关联。每个失败记录需含错误码及具体缺失或不合格输入，不能以空文件充当完成产物。

### 2.4 仅限开发材料的逐Study观测恢复

材料范围来自既定 `partition_manifest.json` 与开发ID清单，只读取身份和划分，不读取全量表型。逐材料向USDA GRIN-Global查询protein观测，先按配置随机选定20个开发材料，核对身份、页面完整性与来源版本，分别记录当前观测差异及历史汇总一致性的证据。完整历史恢复须在20材料页面与汇总一致性全部通过后，再取得其余材料。入口可按材料查询不代表历史数据可稳定、完整地自动获取，试查须保留页面版本及解析结果。

记录包含 `accession_id, study_id, value, inventory, method, source, source_hash`。另保存来源版本、查询时间、材料处理结论及异常；同一材料内的Study、库存和方法身份须能核对，不能按显示值相同擅自去重，也不能根据 `Sample Size` 推断未公开重复。每个请求与返回的材料身份均须属于开发白名单，异常页面不得保存封存观测。

汇总继续使用 `data.protein` 的排除Study与等权规则。比较只读取严格限制范围的开发标签接口，不重新生成标签或样本划分。禁止读取 `phenotype_protein_raw.tsv` 后过滤ID，禁止重跑34个Study全量HTML或解析划分前全队列表。

本轮可在许可开发材料内定向查询当前公开观测，描述跨Study差异，不要求先恢复旧来源精度。页面须验证材料身份、描述符、Study、值和来源版本，标签及划分保持不变。历史汇总一致性的严格验收仍需旧来源逐条公布精度证据；证据不足记 `STUDY_AUDIT_UNAVAILABLE`，不能把当前观测的描述性一致性写成完整历史恢复通过。

精度证据齐全后，按 `pretraining.study` 确定传播规则。单条官方公布值的末位单位为 \(q\)，舍入界为 \(q/2\)。若材料有 \(S\) 个保留Study，第 \(s\) 个Study有 \(n_s\) 条发布值，其等权汇总的舍入界为

\[
B=\frac{1}{S}\sum_{s=1}^{S}\frac{1}{n_s}\sum_{j=1}^{n_s}\frac{q_{sj}}{2}.
\]

容差为旧来源与新来源的 \(B\) 之和，再加配置规定的float64舍入项 \(k\epsilon_{64}(1+|\bar y_{\rm old}|+|\bar y_{\rm new}|)\)，\(k\) 读取配置。新来源精度须保留原字符串；精度依据缺失时停止汇总验收。容差不得依据观测差异倒推。Study或库存覆盖变化须单独记录。

所有14,020个许可材料均须有来源处理结论；记录不含封存ID，来源可复核，排除规则及汇总一致性通过，并报告跨Study差异。发现历史版本变化记 `SOURCE_VERSION_DRIFT`，保留原标签；无法取得完整历史观测记 `STUDY_AUDIT_UNAVAILABLE`。无法恢复或缺项不能算作逐Study核查通过。

## 3. 特征构造的唯一规则

**区域选择。** 窗口长度、最多窗口数与种子读取唯一配置。外部 BED 在源组装按中心生成固定长度窗口，跨染色体边界或含非 A/C/G/T 参考碱基的窗口删除并记录原因；SoyBase 映射面板转移完整源中心窗口，不在目标参考重新取中点。SNP 目录条件、哈希输入及映射版本读取 `regions` 与 `regions.mapping`，依摘要及固定 ID 并列规则接受非重叠候选，处理顺序见[任务书 §3.2](任务书.md)。选择不读取任何项目表型或测试基因型质量；每折随后仅用训练质量决定哪些已选窗口可用，不再补选新的窗口。

**位点处理。** 每个内／外层训练集独立计算调用率与均值。调用率不足的位点不进入该折剂量目录。窗口中若包含被剔除位点、已知未建模变异或无法确认的参考映射，则该窗口在该折整体禁用，以免教师与基线信息量不同。保留低频和训练单态位点；训练单态列均为零，但测试列按原始训练均值变换，不人为归零整个测试列。若训练中完全无调用，调用率规则会剔除该位点。

**可信单倍型。** 全纯合且全已调用窗口直接复制两份序列；仅一个未定相杂合 SNP 时，两条等位序列的集合唯一，可构造后取 F 之和；两个及以上未定相杂合 SNP 则无效。已定相窗口要求所有相位及调用均有效。样本窗口有任何缺失基因型时，不用均值剂量制造虚构序列；A 可用均值填补剂量计算，但 R\_raw=0、U\_raw=A，并保存 mask=0。训练有效比例低于0\.95的窗口从所有功能对照同时删除。

**教师接口。** 对所有参考、单变异和单倍型序列使用相同窗口、方向、tokenizer和推理配置。`eval()`，关闭梯度和随机 dropout；默认正链，不另加未预注册的反向互补平均。当前教师按配置固定模型微批次为 1，外部请求的批次与顺序不得改变单序列推理定义；该规则进入版本与保存分数的版本与序列标识。类别映射经官方任务标签核验后，输出 `logits[:,positive]-logits[:,negative]`。直接读取原始 logits，不能由低精度、接近0或1的概率反求 logit。该定义只适用于二类别头；不把多标签 sigmoid 接口混入。

按 `(teacher_revision, tokenizer_hash, output_definition, dtype, sequence_sha256)` 缓存标量。同一序列不得因“参考／变异”角色不同而获得不同输出。不同训练目录导致个人序列变化时必须形成新缓存键。主分析使用精确单变异扫描，近似 ISM 不得混入。

**构造与中心化。** 先计算原始 D、A=QD、U 和 R=U−A（无效时按上段规则），再只用当前训练均值中心化 A/U/R。保存 `Z=XD` 和 `U=Z+R` 的最大绝对误差，double 运算容差 `1e-8*(1+max_abs(U,Z,R))`。教师原始输出可以float32，差与核运算转float64。这里的容差只检查代数，不证明教师误差足够小。

**数值噪声。** 在64条 成本测量 序列重复推理，记录最大 logit 差 ε。若某功能块的中心化 RMS ≤max\(1e\-8,10ε\)，标为 `NO_RESOLVABLE_SIGNAL` 并关闭该块。教师重复不确定性超过1e\-5时先调查环境；不得用平均对角为1归一化把噪声放大为可用核。所有有效核再用 `c=||B||²_F/n` 整体归一化。

R 缺失置零可能形成覆盖信号，必须报告按覆盖率分层的配对误差；做同一批窗口、同一批完整调用材料的敏感性分析，全部模型共同重拟合。若此子集不足以完成预定分组评价，报告无法确认余项的覆盖稳健性，不能判为通过。

## 4. 求解与对照的精确定义

### 4.1 可复用求解过程

```Plaintext
fix source manifests, phenotype semantics, allowed development IDs, and splits
select external windows without phenotype
for each outer split:
    for each inner split within outer_train_budget:
        fit variant QC and imputation using inner_train only
        build reference / variant / valid haplotype features (reuse outputs of fixed F only)
        fit region validity and centering using inner_train only
        build raw and cross kernels; normalize using training trace
        for family in preregistered model families:
            for each unique allowed mixture w:
                K = sum(w[s] * K_s)
                eigendecompose K once
                for rho in fixed grid:
                    alpha = solve(K + n*rho*I, y - mean(y))
                    predict inner_validation; append squared errors by sample ID
    select each family's configuration by pooled inner MSE and fixed tie rules
    refit all preprocessing and selected configurations on outer_train_budget
    predict outer_validation once; save predictions without subsequent selection and diagnostics
aggregate paired outer predictions; produce descriptive uncertainty and decisions
do not load sealed outcomes
```

当特征中心化且只设截距时，$\alpha=(K+n\rho I)^{-1}(y-\bar y)$，预测为 $\bar y+K_{*T}\alpha$。若以后加固定协变量 C，不能继续直接使用ȳ公式；须采用广义最小二乘 `b=(CᵀV⁻¹C)⁻¹CᵀV⁻¹y`，α=V⁻¹\(y−Cb\)，并同步更新全部对照。本版不加PC固定效应；群体外推通过分组评价检验，不事后只给某个模型增加PC。

每族选择 pooled inner MSE 最小者。误差在 `1e-10*max(1,best_MSE)` 内视为数值并列：先少非零核，再偏向加性核权重大，再较大ρ，最后按配置序列号。不是“一倍标准误”规则。组合模型选择程序只在内层从 M0/M1/M2/MU/ElasticNet 选一族；外层同时保存固定族结果，以供科学比较。内层选定模型的外层误差用于评价这一选择流程，不能用全部外层结果挑族后再称无偏。

### 4.2 必做对照

|标识|核／特征|参数与公平性约束|
|---|---|---|
|M0|KA|配置中的ρ网格；等价于当前剂量定义下的Ridge，不声称复现每一种GBLUP尺度|
|EN|同一X|l1\_ratio 和 α\_max 比例读取配置 `baselines.elasticnet`；α\_max=\|\|Xᵀy\_c\|\|∞/\(n·l1\_ratio\)，为0则截距；目标与sklearn ElasticNet一致；收敛残差／dual\_gap记录|
|M1|KA、KF|两核权重\{0,\.25,\.5,\.75,1\}，相同ρ网格|
|M2|KA、KF、KR|三核步长\.25单纯形，共15权重；不得自增核类别|
|MU|KA、KU|两核相同网格；与M2使用同一原始U，不能再另加教师信息|
|MW|KA、K\_RBF\(U\)|WMKRR路线适配；两核相同权重／ρ网格，固定训练距离中位数带宽|
|MWG|K\_RBF\(X\)、K\_RBF\(U\)|双高斯核路线适配；两核相同权重／ρ网格，不能用额外表达观测|
|MD|KA、KD|v\_j=Σ\_g d\_jg²，KD\_raw=X diag\(v\)Xᵀ；全核迹归一化；它是“相同教师、去掉先验非对角项”对照|
|MP|KA、KF\_perm|在每窗口内按训练 MAF 分层置乱 d，区间边界、重复数和 seed 派生规则读取配置 `controls`，最后区间包含右端点；小于2位点的层不动，报告有效置乱比例；各重复逐个完整调参，不选最优seed|
|MHap|KA、KHap|训练中观察到的单倍型类别计数为列；未知类别测试计数全0；列按训练均值中心化；无效窗口用训练平均类别计数（中心化后0）；拼接后整体迹归一化|
|MLocal|KA、KLocal|同一窗口的X\_g；每窗口高斯核 exp\(−\|\|x\_i−x\_j\|\|²/\(2σ\_g²\)\)，σ\_g²为训练非零两两距离平方的中位数；无非零距离则删除。各局部核按训练中心化、平均对角为1后等权平均，再归一化；无带宽搜索|
|FU|U\-only Ridge|KU、相同ρ网格；U按本规范缺失规则，不额外PCA|
|FU\-GBRT|同一中心化U|sklearn GradientBoostingRegressor，损失、候选网格及叶节点规则读取配置 `baselines.gbrt`，seed 读取顶层配置；内层选择；称Epi\-PRS路线适配，不称原论文复现|
|MI|KA、KI|同一可用窗口及 R 有效性掩码；拼接所有阶数≥2的 ALT 单倍型共现计数，不使用教师权重；无效窗口原始计数为0，之后只按训练均值中心化并整体迹归一化；两核相同网格|
|MI3|KA、KF、KI|与M2共用KA、KF、三核权重及rho网格，只将余项核换为无教师权重的交互核|
|MRPerm3|KA、KF、KR\_perm|与M2共用KA、KF、三核权重及rho网格；与同编号MRPerm共用置乱系数和余项核，逐次报告|
|MRPerm|KA、KR\_perm|按窗口 SNP 数分层，置乱整条教师二阶／更高阶系数向量；有效性掩码、原始零规则及中心化与 R 相同；固定重复数和子流，每次完整选参，不选最优 seed|

以下共现分解针对中心化前的余项；构核前仍按训练均值中心化。双 SNP 窗口的余项严格为 `R_g=Δ_g t_g`，Δ 是教师二阶差分，t 是两条可信单倍型同时携带两 ALT 的数量。三 SNP 窗口保留三项二阶和一项三阶共现及完整教师系数，不能退化为单一双位点项。

MI、MRPerm保留为两核辅助对照。余项教师权重的主要比较使用MI3和MRPerm3，保证与M2的核数和搜索规则相同；记录零信号核导致的实际搜索空间差异。

科学归因分别报告M1对MD／MP及M2对完整功能、普通局部和匹配三核对照的结果，不能解释为因果证据。

新增三核对照使用实验v5，输入、教师及既定划分保持不变；旧外层结果仅作开发证据。

MW／MWG 的 RBF\(B\) 使用 exp\(−\|\|b\_i−b\_j\|\|²/\(2σ\_B²\)\)，σ\_B²为训练样本非零距离平方的中位数；无非零距离则该核关闭。X的距离可由原始XXᵀ与对角计算，无需形成另一个巨型X。U使用与MU相同的目录、窗口、缺失和中心化规则。高斯核再按训练中心化、平均对角为1归一化，测试公式如下；不逐功能列标准化。此为统一预算适配，不复现原WMKRR的200次贝叶斯调参、原表达训练集或全部数据处理。

ElasticNet α\_max须在每个内层训练集重新计算，不能用外层或全开发标签。外层重拟合选中的比例和l1\_ratio，而非直接复用内层某个绝对α。max\_iter、tol 读取配置 `baselines.elasticnet`；未收敛的配置记失败，不能静默作为劣分淘汰。若全部失败，结果状态是基线未完成，不能宣布新方法胜出。

原始高斯核的测试中心化公式：`K_*T^c=K_*T-rowmean_T(K_*T)-colmean_T(K_TT)+mean(K_TT)`；再除训练中心化核的平均对角。不同窗口先按各自有效目录计算；相同位点数与覆盖控制对所有功能比较一致。KHap 对未见类别不共享效应，是预定泛化规则，不许把测试类别频率用于拟合。

MP 置乱不保证破坏全部功能信息，尤其单SNP窗口或强LD窗口；它仅作有符号局部映射的有限负对照。不能因为MP阴性就证明教师具有生物机制解释。每个模型实际搜索数不同，记录全部配置数；比较M2与MU时再报告等预算敏感性，按固定哈希抽取M2权重且必须含KA，权重数及重复数读取配置 `controls`，不择优，防止把搜索预算当贡献。控制子流按顶层 seed、control\_id、repeat\_id 派生，MP 的 control\_id=0，等预算对照为1，MRPerm为2；每次运行保存实际子流及哈希排序规则。

### 4.3 参考锚点敏感性

主锚点由当前数据版本的已核验参考 FASTA 固定，读取配置 `data.reference_build` 与 `regions.fasta`；本版为 Wm82.gnm2.DTC4。替代锚点为每窗口训练集最常见可信单倍型（并列按序列哈希），测试数据不参与。若该锚点在位点j携带原ALT，局部替换方向改为ALT→REF，相应剂量q′\_j=2−q\_j；否则q′=q。重新精确计算d′、A′、U′、R′。此时中心化的一阶映射为 `Z′=X diag(sign) D′`，sign在反向位点为−1。不得仅更换F\(reference\)而继续使用原d、原剂量方向。比较完整重拟合的M1/M2/MU和权重稳定性；不选择更好的锚点作为主结果。

### 4.4 v6之后的最小功能特异性比较

符号对照 `MSign` 保留每个SNP的一阶教师系数绝对值，以独立Rademacher乘子改变其符号。随机子流由配置的seed、对照编号、重复号及原窗口索引确定，在各折保持一致；原MD保持为主对角对照。比较 `M1={A,F}` 与 `MSign={A,F_sign}`，使用相同两核权重及ρ网格、内层调参和外层材料。保存实际非零非对角项改变比例；窗口整体符号翻转不会改变该窗口核，因此不能仅凭系数改变声称符号关系全部被破坏。

窗口移除对象只依据v6已保存的外层训练余项列方差占比确定，窗口身份在配置中预先写明。移除该窗口的功能、余项、对角、局部及单倍型表示，保留全部全局加性SNP、原教师输出、标签及分组清单；各模型共同重新进行训练侧处理和内层调参。完整面板与移除面板分别保存版本和预测，结果属于v6之后的方法开发分析。

128／512／2048预算使用原有按组嵌套清单；主预算定义保持512，当前敏感性预算读取配置 `follow_up.training_budget`。512沿用完整面板结果；2048先完成单外折的实际成本测量，再根据耗时和资源决定全十折安排，不按512成本线性外推。当前不安排720＋1,200完整模拟矩阵或封存评价。

### 5.2 合成验收矩阵

只生成数值基因型与表型，不生成生物实验对象。固定 n∈\{128,512\}、M=256、G=32、每窗8位点；30个重复seed，训练/验证/测试按60%/20%/20%划分，测试只供该次合成评价。每块共享潜变量产生相关0/1单倍型，两条单倍型独立生成；另加完全纯合版本。所有机制标准化信号到方差1，加独立N\(0,1\)噪声，避免机制间信噪比不一致。

|机制|y的信号|应检查的结论，不预定获胜者|
|---|---|---|
|S0 纯加性|Xβ，β独立高斯|附加核选择是否过拟合；M0能否正确回退|
|S1 对角先验|β\_j尺度与Σd\_jg²相关，方向独立|KD能否解释全部功能收益|
|S2 相关先验|β=Dθ\+η|功能协方差匹配时是否有可检出的样本效率差异|
|S3 教师一致|Xβ\+Rγ，教师为已知局部二次函数|M2、MU、普通局部核之间的先验差异|
|S4 教师错配|同一H上独立随机类别效应；F与y机制独立|KHap可解释而教师压缩丢失的信号|
|S5 混杂与缺失|y含群体项；缺失率随群体变化，教师独立|随机分区假增益、组外推及mask敏感性是否揭露问题|

D为固定随机有符号稀疏矩阵（每位点只属于一个窗口），S0/S1/S2中教师取线性F；S3用每窗前两位点乘积加线性F；S4/S5用同样F但独立生成性状信号。S1若R=0，M2关闭KR是正确行为。每次报告真实生成信号的oracle MSE、噪声方差、模型MSE及失败次数；若oracle均不能区分机制，记录模拟功效不足并修正该模拟设计；不据此禁止符合本协议的开发评价。

**可直接编码的生成约定。** 每个组合的种子由 `SeedSequence([20261010, mechanism_id, n, homozygous_flag, repeat_id])` 生成独立子流，repeat\_id=0…29。先生成完整基因型，再产生性状与缺失掩码，最后固定划分。

每个个体、每窗口、每条同源染色体抽 z∼Bernoulli\(0\.25\)，每位点以概率0\.8复制z，否则独立抽Bernoulli\(0\.25\)；纯合模式只生成一条再复制。D的每个非零值独立N\(0,1/8\)，每位点只连接自身窗口。参考单倍型全0。

S0—S2的F\_g\(h\)=Σ\_j d\_jg h\_j，S3—S5再加2h\_1h\_2。

随机系数独立于D和基因型：S0取β\_j∼N\(0,1/M\)；S1取β\_j=√\(Σ\_g d\_jg²\)ε\_j、ε\_j∼N\(0,1\)；S2取θ\_g∼N\(0,1/G\)、η\_j∼N\(0,0\.1/M\)，β=Dθ\+η；S3取β\_j∼N\(0,0\.1/M\)、γ\_g∼N\(0,1/G\)；S4为每窗口全部256种单倍型独立抽效应a\_gh∼N\(0,1/G\)，信号Σ\_g\[a\_g,h1\+a\_g,h2\]。

S5另抽群体s\_i∼Bernoulli\(0\.5\)，将z的成功概率改为0\.1\+0\.6s\_i；信号为2s\_i加一个与D独立的加性分量，β\_j∼N\(0,0\.1/M\)。缺失概率为0\.005\+0\.02s\_i，先生成真信号再掩盖观测基因型；由高缺失导致窗口全部被关闭是应报告的可行性失败，不为获得曲线而放宽0\.95阈值。

所有机制先对完整无噪声信号减本次生成总体均值并除其标准差，再加N\(0,1\)噪声；此步骤属于生成器，不把总体统计提供给预测模型。记录真实信号，oracle预测即该信号，oracle测试误差为实际噪声平方均值；oracle不能作为实际预测模型。

随机划分用固定排列前floor\(0\.6n\)训练、后floor\(0\.2n\)验证、其余测试；合成最小验收以该验证集选配置，不声称嵌套真数据评价。

S5另报告两种群体外推：s=0内80%训练/20%验证、全部s=1测试，及相反方向；分组不足记失败。所有机制同时报告纯合与已定相双倍体结果，不随机制造相位错误；相位错误属于单元测试。

机制、纯合模式、样本量与重复共6×2×2×30=720个数据集；30次分布用于功效诊断，不选出有利seed。

**真实实验顺序：** 完成输入读取与数值检查，核验本版固定面板的有效性和完整比较成本，再完成E\-A/E\-B及同一面板的E\-C/E\-D，随后开展E\-E/E\-F。原文“256窗口成本与有效性”是否还要求独立成本试验，见任务书待确认事项；本版35窗面板保持不变。

M1无增益不构成跳过M2／MU／MW／MWG的依据；局部非线性可能在一阶特征无效时有用。若总成本不允许完成E\-C，记录COMPARISON\_INCOMPLETE并停止扩大，不作余项阴性结论。本研究允许的否定结论是“目前不值得扩大”，不是“所有非线性算法无效”。

### 5.3 真实开发基因型条件下的稀疏功效实验

使用14,020个开发材料、41,346个目录SNP，以及既定31个双SNP窗和4个三SNP窗。保留真实LD、MAF、缺失和近重复组；使用现有教师系数与原始调用有效性掩码，不读取真实protein。每次生成合成表型后，按主预算及既定十外折、四内折完成配对评价；十折不是独立重复。其他预算属于后续敏感性分析。

| 情景 | 功能生成信号 | 理论oracle增量 | 用途 |
| --- | --- | --- | --- |
| N0 | 无，仅加性信号 | 0% | 检查完整继续判据的误触发 |
| F2 | \(Z\theta\) | 2% | 一阶先验目标功效 |
| F5 | \(Z\theta\) | 5% | 一阶先验正对照 |
| R2 | \(R\gamma\) | 2% | 余项目标功效 |
| R5 | \(R\gamma\) | 5% | 余项正对照 |
| RP5 | 按窗SNP数分层置乱教师高阶系数，再乘 \(\gamma\) | 5% | 检查错误教师权重归因 |

情景编号、重复、随机子流、分布和数值只维护在 `pretraining.synthetic_sparse`。每情景200次，共1,200个实例；根种子为 `SeedSequence([seed, scenario_id, repeat_id])`，子流顺序按配置固定，用于加性效应、功能系数、RP5置乱和噪声。不能按结果挑seed或调整信号。

加性生成函数使用全部既定目录位点，独立系数 \(\beta_j\sim N(0,1/M)\)，按生成总体中心化后标准化至配置规定的方差。每个实例独立抽取系数，未调用剂量只在生成器内用开发总体位点均值处理；完全无调用列记零且记录。功能系数为独立 \(\theta_g,\gamma_g\sim N(0,1/G)\)，先形成指定信号，再以生成总体均值与方差整体标准化。RP5置乱完整高阶系数向量，按实际窗口SNP数分层，保留原有效性规则。

生成器可用开发总体统计量定义已知合成函数；这些统计量不能提供给预测模型。各内外层预测仍独立拟合自己的QC、填补、窗口有效性和中心化。生成用Z/R由同一固定原始功能定义取得，在生成总体内中心化；不按各评价折重新生成表型。窗口不按方差重加权，也不把功能信号对全X正交化。

对标准化功能信号 \(h\)，生成

\[
y=f_A+c_\delta h+\epsilon,\qquad \epsilon\sim N(0,1),\qquad c_\delta=\sqrt{\frac{\delta}{1-\delta}}.
\]

N0的功能项为零。加性oracle直接预测已知 \(f_A\)，完整oracle预测 \(f_A+c_\delta h\)。\(\delta\) 是这两个已知函数在噪声期望下的MSE改善比例，不是拟合M2相对M0的保证，也不等于所有可能加性模型的最优风险差。报告实际oracle误差、信号方差、噪声方差及交叉项，不把有限样本实测比例强制调到理论值。

检测事件复用正式继续判据：主模型对内层从M0／EN选出的强加性流程达到配置规定的相对MSE增量和方向一致比例；相关匹配对照的pooled MSE须逐项更高，全部固定置乱重复都报告，不选择有利对照。F情景检查M1对MD／MP，R情景检查M2对M1、MU、MW、MWG、MHap、MLocal、MI／MRPerm、MI3／MRPerm3。完整调用、锚点与搜索预算分析不能使主判断失效。N0统计M1或M2任一完整继续事件；RP5统计错误教师权重下的M2继续事件，不把它计作正确教师的正对照功效。

检测率以全部预注册实例为分母。失败实例不能删除或替换，记为未检测且单独记录技术失败；缺实例、缺折、必做基线不收敛均不能通过技术完整性验收。记录逐实例seed、来源版本、配对ID、全部预测、实际增量、十折方向、主要失败原因及95% Wilson区间。

| 评价项目 | 条件与记录 |
| --- | --- |
| 技术完整性 | 全部情景与实例完成，U=Z+R、核PSD、训练隔离、oracle及配对ID按已有容差通过 |
| N0校准 | 完整继续事件误触发率不超过配置上限；校准失败先检查评价程序 |
| 5%正对照 | F5、R5分别达到配置检测率门槛；不足时分项记 `LOW_POWER` |
| 2%目标 | F2、R2分别达到门槛，才可称对应效应具备预定检测能力 |
| 功效解释 | 任一所需正对照或目标功效不足，整体记 `POWER_LIMITED`；技术状态单独保留 |
| 稳定性 | 报告Wilson区间、实际信号方差及前三窗口贡献；窗口贡献同时保留协方差交叉项，不冒充因果分解 |

通过率判断使用预定点估计，Wilson区间用于描述精度，不另引入区间下限判据。更多合成重复提高功效估计精度，不能改善固定模型的统计功效。

先运行配置指定的12个实例（每情景前两个重复）检查内存、数值一致性与资源需求；它们只作试测，不据此改变情景、效应或成功条件。正式实例是否复用试测记录须证明运行要求与结果完全一致；不能用只有部分折的试测替代正式实例。核矩阵与分解只有在不依赖合成响应、版本一致且预测与完整计算一致时可跨重复复用。

## 6. 指标、日志与验收判据

计算 pooled $\mathrm{MSE}=\sum_i(y_i-\hat y_i)^2/N$；相对增益 `1−MSE_candidate/MSE_baseline`；Q²=$1-\sum_i(y_i-\hat y_i)^2/\sum_i(y_i-\bar y_{T(i)})^2$，其中 $\bar y_{T(i)}$ 为预测材料 $i$ 时实际拟合的外层训练预算子集均值。PCC在响应或预测常数时记NA，不用0掩盖。每项对照都用相同外层材料。预定强加性基线是在内层从M0/EN选择的流程；不能外层看哪个更好再逐样本拼接。

不确定性以group为抽样单位，对同一组的全部配对外层误差一起重采样2000次；重复CV先在每个材料上平均各次平方误差，不先平均预测再算MSE。报告2\.5%/97\.5%分位区间并注明它仅为开发描述性区间，未完整计入重拟合与模型搜索不确定性。不实施未经证明的“独立折显著性检验”。

`kernel_diagnostics`至少含各核迹、有效秩、最小特征值、上三角相关矩阵、与KA的中心核对齐度、c\_s、有效窗口数。若两个核高度相近，只报告无法可靠归因，不用不稳定权重解释生物通路。测试阶段同时保存窗口覆盖、低频位点数、未见单倍型比例；它们用于误差分层，不能据测试标签重新过滤。

性能研究继续阈值读取配置：本版相对MSE降低≥2%，至少80%的外层分区同向（十折为至少八折），且完整覆盖分析未使结论反转。M2还须分别胜过M1、MU、MW、MWG及普通局部/单倍型对照，才可继续研究余项特有贡献。达不到不等于统计证明无效；区间宽则记录 `INCONCLUSIVE_UNDER_BUDGET`。统计比较完成度不足或强基线失败时记录 `COMPARISON_INCOMPLETE`，不能记算法成功。

日志必须记录CPU/GPU型号、软件版本、线程数、教师前向次数、唯一序列数、已有分数复用比例、推理时间、每折构核及求解时间、峰值内存、实际配置数、失败配置及重试。执行完后只允许根据实际产物填写状态，不沿用README中的完成声明。

**评价约束：** 训练输入、模型选择与解释均遵守当前分区和证据范围。封存表型禁止读取；外层标签不能用于早停或更换教师，全队列 GWAS／PCA／均值不能决定训练输入。未定相单倍型不能随机拼接。官方仓库存在不等于复现成功，预测提升不等于因果机制，组合既有模型不等于原理创新。

## 7. 真实protein开发评价的执行与证据

现有 `evaluate` 执行本轮十折开发评价，协议版本见唯一配置。Study历史精度、原720组机制模拟、新增1,200组功效模拟、跨实例复用及完整预训练证据均不再作为执行前提，不新增授权系统或评价入口。未完成研究记为 `NOT_COMPLETED`；来源不可恢复及未知功效如实列为解释限制。

训练前核验实际输入、来源和划分身份、许可开发ID范围、既定教师及35窗。保持现有表型汇总、组约束十外折／四内折、512预算及全部模型与搜索空间。QC、缺失填补、中心化和核尺度仅由当前训练分区确定；调参仅使用内层。封存表型始终隔离。

实际输入错误、同源材料跨折泄漏或数值失败须停止并修复。全部模型完整执行并通过现有收敛和残差检查；不跳过失败模型，不修改搜索空间以获得完成状态。

每次运行保存配置与实现摘要、输入及划分哈希、各折材料身份、内层全部候选分数与数值记录、所选参数、外层重拟合收敛记录、各模型预测及文件哈希。全部外折预测保存后，再读取对应开发观测完成配对评价。

主参照为内层从M0／EN选择的 `AdditiveSelection`，保留相对M0的辅助结果。报告合并MSE、各外折改进幅度与方向一致性，及M1对MD／每个MP、M2对MU／MI3／每个MRPerm3等既定对照的逐项比较。区间是条件于这些预测的开发描述，不构成独立验证。

未超过加性参照时优先分析失败原因；超过加性而未超过匹配对照时，不将增益归因于教师独特价值。出现明确增量后，优先研究高方差窗口敏感性、Study间异质性与针对性模拟。后续修改均留档，保留验证集的最终评价另行授权。
