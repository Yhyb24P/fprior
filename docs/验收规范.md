# 最小实现与实验验收规范

版本：2026\-10\-10。规范模型：主文 §3 的有限候选多核岭回归。这里的数值阈值、网格与停止规则均为**设计选择**，不是已证明最优参数。目标是使一个实现版本可以被独立检查，不要求先完成大型神经网络复现。

## 1\. 执行目标、上下文与边界

**目标：** 实现 M0/M1/M2/MU 和能区分功能先验贡献的最小对照；首先证明输入、特征与求解一致，再评价公开开发分区的连续性状。必要上下文是[研究方案](研究方案.md)的数学定义、[唯一配置](../configs/funcprior.toml)和既有划分。文中 E1—E11 引用的外部文献审计附件未随本目录提供，相关文献核验仍需补齐。

**边界：** 不访问封存表型；不修改既有样本划分；不将历史报告分数作为本轮结果；不默认真实数据或教师已在本机可用。先实现可测试的线性代数和 mock teacher，再接真实教师。未知性状语义、未定位的参考版本和不可恢复的相位均不能由代码 Agent 猜测。

**验收状态：** `ALGEBRA_VERIFIED`、`TEACHER_INTERFACE_VERIFIED`、`DATA_READY`、`DEVELOPMENT_EVALUATED` 分别记录。前一状态不自动证明后一状态；方案编写阶段记载了合成代数核验；本轮数学核心另有 23 项合成单元测试通过（见 README），但完整机制验收、流水线与真实教师验收尚未完成，不能据此升级全部状态。最终交付物必须同时包含预测、配置、版本、耗时和失败记录。

主性状 `primary_trait_id` 必填，不赋任意默认值。原拟南芥文档的 Pilot／FT10 讨论不决定本项目目标；本项目目标必须在查看本轮预测前写入配置。若无已确定目标，程序只做无表型验证，返回 `TARGET_UNSPECIFIED`。

### 2\.2 配置与预算

实验参数的唯一来源是 [`configs/funcprior.toml`](../configs/funcprior.toml)，本规范不维护另一份默认配置。当前配置为 SoyBase protein 任务草案，物种参考、固定目录多 SNP 候选规则、训练预算及既有十折外层安排见[任务书](任务书.md)。本规范保留原拟南芥输入示例和通用数学验收要求；涉及大豆适配的约定以新任务版本为准，不能把配置已填写视为输入就绪或能力已实现。

预算是首轮上限，实际硬件与速度必须实测；不以用户历史机器规格推定当前可用资源。64条推理包含参考、单变异、多变异各类；重复一遍验证缓存与确定性。若投影超限，返回成本表并停止扩大，不按教师分数或表型临时选择“便宜又有效”的窗口。调整上限或窗口数需新配置版本。

内外层折数及一致性判据读取当前版本配置，并核验实际冻结清单；SoyBase v3 为开发集组约束十折外层、各训练预算四折内层。少于规定折数的独立组不能称为完成相应验证。连续响应中的真实极值不能自动视为删失或截尾处理。

保存：`config.json`、`input_manifest.json`、`teacher_manifest.json`、`fold_manifest.json`、`variant_qc.tsv`、`region_validity.tsv`、`feature_cache_manifest.jsonl`、`kernel_diagnostics.json`、`inner_scores.tsv`、`selected_model.json`、`predictions.parquet`、`metrics.json`、`timing.json`、`tests.json`、`run_status.json`。格式可用等价 TSV/JSON 替换 parquet，但字段不能缺省。

## 3\. 特征构造的唯一规则

**区域选择。** 窗口长度、最多窗口数与种子读取唯一配置。外部 BED 在源组装按中心生成固定长度窗口，跨染色体边界或含非 A/C/G/T 参考碱基的窗口删除并记录原因；SoyBase 映射面板转移完整源中心窗口，不在目标参考重新取中点。SNP 目录条件、哈希输入及映射版本读取 `regions` 与 `regions.mapping`，依摘要及固定 ID 并列规则接受非重叠候选，处理顺序见[任务书 §四](任务书.md)。选择不读取任何项目表型或测试基因型质量；每折随后仅用训练质量决定哪些已选窗口可用，不再补选新的窗口。

**位点处理。** 每个内／外层训练集独立计算调用率与均值。调用率不足的位点不进入该折剂量目录。窗口中若包含被剔除位点、已知未建模变异或无法确认的参考映射，则该窗口在该折整体禁用，以免教师与基线信息量不同。保留低频和训练单态位点；训练单态列均为零，但测试列按原始训练均值变换，不人为归零整个测试列。若训练中完全无调用，调用率规则会剔除该位点。

**可信单倍型。** 全纯合且全已调用窗口直接复制两份序列；仅一个未定相杂合 SNP 时，两条等位序列的集合唯一，可构造后取 F 之和；两个及以上未定相杂合 SNP 则无效。已定相窗口要求所有相位及调用均有效。样本窗口有任何缺失基因型时，不用均值剂量制造虚构序列；A 可用均值填补剂量计算，但 R\_raw=0、U\_raw=A，并保存 mask=0。训练有效比例低于0\.95的窗口从所有功能对照同时删除。

**教师接口。** 对所有参考、单变异和单倍型序列使用相同窗口、方向、tokenizer和推理配置。`eval()`，关闭梯度和随机 dropout；默认正链，不另加未预注册的反向互补平均。当前教师按配置固定模型微批次为 1，外部请求的批次与顺序不得改变单序列推理定义；该规则进入版本与缓存身份。类别映射经官方任务标签核验后，输出 `logits[:,positive]-logits[:,negative]`。直接读取原始 logits，不能由低精度、接近0或1的概率反求 logit。该定义只适用于二类别头；不把多标签 sigmoid 接口混入。

按 `(teacher_revision, tokenizer_hash, output_definition, dtype, sequence_sha256)` 缓存标量。同一序列不得因“参考／变异”角色不同而获得不同输出。不同训练目录导致个人序列变化时必须形成新缓存键。主分析使用精确单变异扫描，近似 ISM 不得混入。

**构造与中心化。** 先计算原始 D、A=QD、U 和 R=U−A（无效时按上段规则），再只用当前训练均值中心化 A/U/R。保存 `Z=XD` 和 `U=Z+R` 的最大绝对误差，double 运算容差 `1e-8*(1+max_abs(U,Z,R))`。教师原始输出可以float32，差与核运算转float64。这里的容差只检查代数，不证明教师误差足够小。

**数值噪声。** 在64条 profiling 序列重复推理，记录最大 logit 差 ε。若某功能块的中心化 RMS ≤max\(1e\-8,10ε\)，标为 `NO_RESOLVABLE_SIGNAL` 并关闭该块。教师重复不确定性超过1e\-5时先调查环境；不得用平均对角为1归一化把噪声放大为可用核。所有有效核再用 `c=||B||²_F/n` 整体归一化。

R 缺失置零可能形成覆盖信号，必须报告按覆盖率分层的配对误差；做同一批窗口、同一批完整调用材料的敏感性分析，全部模型共同重拟合。若此子集不足以完成预定分组评价，报告无法确认余项的覆盖稳健性，不能判为通过。

## 4\. 求解与对照的精确定义

### 4\.1 可复用求解过程

```Plaintext
freeze source manifests, phenotype semantics, allowed development IDs, and splits
select external windows without phenotype
for each outer split:
    for each inner split within outer_train:
        fit variant QC and imputation using inner_train only
        build reference / variant / valid haplotype features (cache frozen F only)
        fit region validity and centering using inner_train only
        build raw and cross kernels; normalize using training trace
        for family in preregistered model families:
            for each unique allowed mixture w:
                K = sum(w[s] * K_s)
                eigendecompose K once
                for rho in fixed grid:
                    alpha = solve(K + n*rho*I, y - mean(y))
                    predict inner_validation; append squared errors by sample ID
    select each family's configuration by pooled inner MSE and fixed tie rules
    refit all preprocessing and selected configurations on outer_train
    predict outer_validation once; save frozen predictions and diagnostics
aggregate paired outer predictions; produce descriptive uncertainty and decisions
do not load sealed outcomes
```

当特征中心化且只设截距时，$\alpha=(K+n\rho I)^{-1}(y-\bar y)$，预测为 $\bar y+K_{*T}\alpha$。若以后加固定协变量 C，不能继续直接使用ȳ公式；须采用广义最小二乘 `b=(CᵀV⁻¹C)⁻¹CᵀV⁻¹y`，α=V⁻¹\(y−Cb\)，并同步更新全部对照。本版不加PC固定效应；群体外推通过分组评价检验，不事后只给某个模型增加PC。

每族选择 pooled inner MSE 最小者。误差在 `1e-10*max(1,best_MSE)` 内视为数值并列：先少非零核，再偏向加性核权重大，再较大ρ，最后按配置序列号。不是“一倍标准误”规则。复合部署流程只在内层从 M0/M1/M2/MU/ElasticNet 选一族；外层同时保存固定族结果，以供科学比较。选择后赢家的外层误差用于评价这一选择流程，不能用全部外层结果挑族后再称无偏。

### 4\.2 必做对照

|标识|核／特征|参数与公平性约束|
|---|---|---|
|M0|KA|主文ρ网格；等价于当前剂量定义下的Ridge，不声称复现每一种GBLUP尺度|
|EN|同一X|l1\_ratio 和 α\_max 比例读取配置 `baselines.elasticnet`；α\_max=\|\|Xᵀy\_c\|\|∞/\(n·l1\_ratio\)，为0则截距；目标与sklearn ElasticNet一致；收敛残差／dual\_gap记录|
|M1|KA、KF|两核权重\{0,\.25,\.5,\.75,1\}，相同ρ网格|
|M2|KA、KF、KR|三核步长\.25单纯形，共15权重；不得自增核类别|
|MU|KA、KU|两核相同网格；与M2使用同一原始U，不能再另加教师信息|
|MW|KA、K\_RBF\(U\)|WMKRR路线适配；两核相同权重／ρ网格，固定训练距离中位数带宽|
|MWG|K\_RBF\(X\)、K\_RBF\(U\)|双高斯核路线适配；两核相同权重／ρ网格，不能用额外表达观测|
|MD|KA、KD|v\_j=Σ\_g d\_jg²，KD\_raw=X diag\(v\)Xᵀ；全核迹归一化；它是“相同教师、去掉先验非对角项”对照|
|MP|KA、KF\_perm|在每窗口内按训练 MAF 分层置乱 d，区间边界、重复数和 seed 派生规则读取配置 `controls`，最后区间包含右端点；小于2位点的层不动，报告有效置乱比例；各重复逐个完整调参，不选最优seed|
|MHap|KA、KHap|训练中观察到的单倍型类别计数为列；未知类别测试计数全0；列按训练均值中心化；无效窗口用训练平均类别计数（中心化后0）；拼接后整体迹归一化|
|MLocal|KA、KLocal|同一窗口的X\_g；每窗口高斯核 exp\(−\|\|x\_i−x\_j\|\|²/\(2σ\_g²\)\)，σ\_g²为训练非零两两距离平方的中位数；无非零距离则删除。各局部核按训练中心化、平均对角为1后等权平均，再归一化；无带宽搜索|
|FU|U\-only Ridge|KU、相同ρ网格；U按主文缺失规则，不额外PCA|
|FU\-GBRT|同一中心化U|sklearn GradientBoostingRegressor，损失、候选网格及叶节点规则读取配置 `baselines.gbrt`，seed 读取顶层配置；内层选择；称Epi\-PRS路线适配，不称原论文复现|
|MI|KA、KI|同一可用窗口及 R 有效性掩码；拼接所有阶数≥2的 ALT 单倍型共现计数，不使用教师权重；无效窗口原始计数为0，之后只按训练均值中心化并整体迹归一化；两核相同网格|
|MRPerm|KA、KR\_perm|按窗口 SNP 数分层，置乱整条教师二阶／更高阶系数向量；有效性掩码、原始零规则及中心化与 R 相同；固定重复数和子流，每次完整选参，不选最优 seed|

双 SNP 窗口的余项严格为 `R_g=Δ_g t_g`，Δ 是教师二阶差分，t 是两条可信单倍型同时携带两 ALT 的数量。三 SNP 窗口保留三项二阶和一项三阶共现及完整教师系数，不能退化为单一双位点项。MI 隔离无教师交互表示，MRPerm 检验窗口间权重配置，均不构成生物机制或因果证据；科学归因须分别报告 M1 对 MD／MP 和 M2 对普通局部、完整 U、MI／MRPerm 的结果。新增对照采用 v4，v3 输入、教师与冻结划分复用但不改写。

MW／MWG 的 RBF\(B\) 使用 exp\(−\|\|b\_i−b\_j\|\|²/\(2σ\_B²\)\)，σ\_B²为训练样本非零距离平方的中位数；无非零距离则该核关闭。X的距离可由原始XXᵀ与对角计算，无需形成另一个巨型X。U使用与MU相同的目录、窗口、缺失和中心化规则。高斯核再按训练中心化、平均对角为1归一化，测试公式如下；不逐功能列标准化。此为统一预算适配，不复现原WMKRR的200次贝叶斯调参、原表达训练集或全部数据处理。

ElasticNet α\_max须在每个内层训练集重新计算，不能用外层或全开发标签。外层重拟合选中的比例和l1\_ratio，而非直接复用内层某个绝对α。max\_iter、tol 读取配置 `baselines.elasticnet`；未收敛的配置记失败，不能静默作为劣分淘汰。若全部失败，结果状态是基线未完成，不能宣布新方法胜出。

原始高斯核的测试中心化公式：`K_*T^c=K_*T-rowmean_T(K_*T)-colmean_T(K_TT)+mean(K_TT)`；再除训练中心化核的平均对角。不同窗口先按各自有效目录计算；相同位点数与覆盖控制对所有功能比较一致。KHap 对未见类别不共享效应，是预定泛化规则，不许把测试类别频率用于拟合。

MP 置乱不保证破坏全部功能信息，尤其单SNP窗口或强LD窗口；它仅作有符号局部映射的有限负对照。不能因为MP阴性就证明教师具有生物机制解释。每个模型实际搜索数不同，记录全部配置数；比较M2与MU时再报告等预算敏感性，按固定哈希抽取M2权重且必须含KA，权重数及重复数读取配置 `controls`，不择优，防止把搜索预算当贡献。控制子流按顶层 seed、control\_id、repeat\_id 派生，MP 的 control\_id=0，等预算对照为1，MRPerm为2；每次运行保存实际子流及哈希排序规则。

### 4\.3 参考锚点敏感性

主锚点由当前数据版本的已核验参考 FASTA 固定，读取配置 `data.reference_build` 与 `regions.fasta`；SoyBase v3 为 Wm82.gnm2.DTC4，TAIR10 仅对应原拟南芥设计。替代锚点为每窗口训练集最常见可信单倍型（并列按序列哈希），测试数据不参与。若该锚点在位点j携带原ALT，局部替换方向改为ALT→REF，相应剂量q′\_j=2−q\_j；否则q′=q。重新精确计算d′、A′、U′、R′。此时中心化的一阶映射为 `Z′=X diag(sign) D′`，sign在反向位点为−1。不得仅更换F\(reference\)而继续使用原d、原剂量方向。比较完整重拟合的M1/M2/MU和权重稳定性；不选择更好的锚点作为主结果。

## 5\. 单元测试与最小实验矩阵

### 5\.1 必须可重复的测试

|测试|构造|验收条件|
|---|---|---|
|ID和目录|故意交换样本／位点映射、重复ID、REF错配|报明确错误，不产生预测|
|坐标|人工8bp参考，窗口边界SNP与BED转换|替换准确；600bp任务边界不足拒绝|
|线性教师|F\(h\)=c\+Σa\_jh\_j|有效窗口R≈0；KR关闭|
|两位点非线性|F=c\+a₁h₁\+a₂h₂\+bh₁h₂|同剂量cis/trans可得不同R；单变异余项为0|

### 5\.2 合成验收矩阵

只生成数值基因型与表型，不生成生物实验对象。固定 n∈\{128,512\}、M=256、G=32、每窗8位点；30个重复seed，训练/验证/测试按60%/20%/20%划分，测试只供该次合成评价。每块共享潜变量产生相关0/1单倍型，两条单倍型独立生成；另加完全纯合版本。所有机制标准化信号到方差1，加独立N\(0,1\)噪声，避免机制间信噪比不一致。

|机制|y的信号|应检查的结论，不预定获胜者|
|---|---|---|
|S0 纯加性|Xβ，β独立高斯|附加核选择是否过拟合；M0能否正确回退|
|S1 对角先验|β\_j尺度与Σd\_jg²相关，方向独立|KD能否解释全部功能收益|
|S2 相关先验|β=Dθ\+η|功能协方差匹配时是否有可检出的样本效率差异|
|S3 教师一致|Xβ\+Rγ，教师为已知局部二次函数|M2、MU、普通局部核之间的先验差异|
|S4 教师错配|同一H上独立随机类别效应；F与y机制独立|KHap可解释而教师压缩丢失的信号|
|S5 混杂与缺失|y含群体项；缺失率随群体变化，教师独立|随机分区假增益、组外推及mask敏感性是否揭露问题|

D为固定随机有符号稀疏矩阵（每位点只属于一个窗口），S0/S1/S2中教师取线性F；S3用每窗前两位点乘积加线性F；S4/S5用同样F但独立生成性状信号。S1若R=0，M2关闭KR是正确行为。每次报告真实生成信号的oracle MSE、噪声方差、模型MSE及失败次数；若oracle均不能区分机制，应先修正实验功效，不扩展真数据。

**可直接编码的生成约定。** 每个组合的种子由 `SeedSequence([20261010, mechanism_id, n, homozygous_flag, repeat_id])` 生成独立子流，repeat\_id=0…29。先生成完整基因型，再产生性状与缺失掩码，最后固定划分。每个个体、每窗口、每条同源染色体抽 z∼Bernoulli\(0\.25\)，每位点以概率0\.8复制z，否则独立抽Bernoulli\(0\.25\)；纯合模式只生成一条再复制。D的每个非零值独立N\(0,1/8\)，每位点只连接自身窗口。参考单倍型全0；S0—S2的F\_g\(h\)=Σ\_j d\_jg h\_j，S3—S5再加2h\_1h\_2。随机系数独立于D和基因型：S0取β\_j∼N\(0,1/M\)；S1取β\_j=√\(Σ\_g d\_jg²\)ε\_j、ε\_j∼N\(0,1\)；S2取θ\_g∼N\(0,1/G\)、η\_j∼N\(0,0\.1/M\)，β=Dθ\+η；S3取β\_j∼N\(0,0\.1/M\)、γ\_g∼N\(0,1/G\)；S4为每窗口全部256种单倍型独立抽效应a\_gh∼N\(0,1/G\)，信号Σ\_g\[a\_g,h1\+a\_g,h2\]。

S5另抽群体s\_i∼Bernoulli\(0\.5\)，将z的成功概率改为0\.1\+0\.6s\_i；信号为2s\_i加一个与D独立的加性分量，β\_j∼N\(0,0\.1/M\)。缺失概率为0\.005\+0\.02s\_i，先生成真信号再掩盖观测基因型；由高缺失导致窗口全部被关闭是应报告的可行性失败，不为获得曲线而放宽0\.95阈值。所有机制先对完整无噪声信号减本次生成总体均值并除其标准差，再加N\(0,1\)噪声；此步骤属于生成器，不把总体统计提供给预测模型。记录真实信号，oracle预测即该信号，oracle测试误差为实际噪声平方均值；不把oracle作为可部署模型。

随机划分用固定排列前floor\(0\.6n\)训练、后floor\(0\.2n\)验证、其余测试；合成最小验收以该验证集选配置，不声称嵌套真数据评价。S5另报告两种群体外推：s=0内80%训练/20%验证、全部s=1测试，及相反方向；分组不足记失败。所有机制同时报告纯合与已定相双倍体结果，不随机制造相位错误；相位错误属于单元测试。机制、纯合模式、样本量与重复共6×2×2×30=720个数据集；30次分布用于功效诊断，不选出有利seed。

**最小真实实验顺序：** 完成所有接口测试→256窗口成本与有效性→完成E\-A/E\-B及同一面板的E\-C/E\-D→对有增益候选做E\-E/E\-F。M1无增益不构成跳过M2／MU／MW／MWG的依据；局部非线性可能在一阶特征无效时有用。若总成本不允许完成E\-C，记录COMPARISON\_INCOMPLETE并停止扩大，不作余项阴性结论。主文允许的否定结论是“目前不值得扩大”，不是“所有非线性算法无效”。

## 6\. 指标、日志与验收判据

计算 pooled $\mathrm{MSE}=\sum_i(y_i-\hat y_i)^2/N$；相对增益 `1−MSE_candidate/MSE_baseline`；Q²=$1-\sum_i(y_i-\hat y_i)^2/\sum_i(y_i-\bar y_{T(i)})^2$，其中 $\bar y_{T(i)}$ 为材料 $i$ 所在外层训练集的均值。PCC在响应或预测常数时记NA，不用0掩盖。每项对照都用相同外层材料。预定强加性基线是在内层从M0/EN选择的流程；不能外层看哪个更好再逐样本拼接。

不确定性以group为抽样单位，对同一组的全部配对外层误差一起重采样2000次；重复CV先在每个材料上平均各次平方误差，不先平均预测再算MSE。报告2\.5%/97\.5%分位区间并注明它仅为开发描述性区间，未完整计入重拟合与模型搜索不确定性。不实施未经证明的“独立折显著性检验”。

`kernel_diagnostics`至少含各核迹、有效秩、最小特征值、上三角相关矩阵、与KA的中心核对齐度、c\_s、有效窗口数。若两个核高度相近，只报告无法可靠归因，不用不稳定权重解释生物通路。测试阶段同时保存窗口覆盖、低频位点数、未见单倍型比例；它们用于误差分层，不能据测试标签重新过滤。

性能研究继续条件按主文：相对MSE降低≥2%，不少于4/5外层分区方向一致，且完整覆盖分析未使结论反转。M2还须分别胜过M1、MU、MW、MWG及普通局部/单倍型对照，才可继续研究余项特有贡献。达不到不等于统计证明无效；区间宽则记录 `INCONCLUSIVE_UNDER_BUDGET`。统计比较完成度不足或强基线失败时记录 `COMPARISON_INCOMPLETE`，不能记算法成功。

日志必须记录CPU/GPU型号、软件版本、线程数、教师前向次数、唯一序列数、缓存命中率、推理时间、每折构核及求解时间、峰值内存、实际配置数、失败配置及重试。执行完后只允许根据实际产物填写状态，不沿用README中的完成声明。

**禁止事项：** 启封表型；用全体GWAS／PCA／均值决定训练输入；用外层标签早停或换教师；随机拼接未定相单倍型；把官方仓库存在当作复现成功；将预测提升称为因果机制；把当前集成重新命名后宣称原理创新。

b=rng.normal(size=m);t=rng.normal(size=g);c=rng.normal(size=g)

def ck(name,a,b,tol=1e-10):
 e=float(np.max(np.abs(np.asarray(a)-np.asarray(b))));checks[name]={'max_abs_error':e,'pass':e<tol};assert e<tol,(name,e)
ck('reparameterization',X@b+Z@t+R@c,X@(b+D@(t-c))+U@c)
ta,tf,th=.6,.2,.7
K=ta*X@X.T+tf*Z@Z.T+th*R@R.T
ck('expanded_kernel',K,ta*X@X.T+(tf+th)*Z@Z.T+th*U@U.T-th*(U@Z.T+Z@U.T))
P=np.block([[ta*np.eye(m)+(tf+th)*D@D.T,-th*D],[-th*D.T,th*np.eye(g)]])

ck('correlated_prior',K,B@P@B.T)

coef=np.linalg.solve(A.T@A+lam*np.eye(A.shape[1]),A.T@y)
ck('primal_dual',A@coef,K@alpha)

# Every local function is a linear readout of haplotype indicators.
