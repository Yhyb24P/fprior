## v6现有结果诊断（未重新训练）

从原预测与五十个训练侧设计记录提取逐折核权重、M0／EN选择边际、M1／M2误差、MP改变比例、核对齐度及逐窗口余项方差，产物见 `runs/20261012_v6_existing_diagnostics/`。六折的内层加性选择未选中事后外层误差较低的一族，平均选择差值为0.084212 MSE；该事后最佳选择仅用于诊断，不替换预定参照。第6折的内层EN优势仅0.004%，第7折M0优势0.220%，反映选择边际较小。

加性选择波动影响了所见增益的幅度。按恒等式将相对主参照的MSE差分解为主参照与M0的差、M0与功能模型的差，前一项分别占M1、M2总差值的71.16%、83.68%；M1、M2相对M0的增益仅为0.293%、0.141%。M1有五折选择纯加性核，M2有两折。这是已有预测的描述性分解，不是因果归属或方差组分估计；主参照仍为预定的AdditiveSelection，详细记录见该目录的 `baseline_gain_decomposition.json`。

第16号窗口 `glyma.Wm82.gnm4.Gm11:8092839-8093340` 的外层训练余项方差平均占84.46%，各折为82.54%–86.01%。MP实际改变系数比例为28.38%–56.76%。F、R、D、I与A的平均中心核对齐度分别为0.273、0.240、0.178、0.469。余项集中与基线选择波动同时存在，单凭这些记录不能确定弱增益的来源；对应预测作用由下述符号和窗口移除比较检查。

## 预算比较与研究判断

三个预算均完成同一开发十折、66套预测及全部规定对照，沿用不读取表型的整组嵌套前缀。主预算仍为512，128／2048为敏感性预算。各折实际样本数、全部指标、逐折比较、等搜索预算对照及两台机器的数值差异集中于[统一比较](../runs/20261012_v6_existing_diagnostics/training_budget_comparison.json)。512采用v7，其原有56套预测与v6相同。

| 预算 | AdditiveSelection MSE | M1 MSE | M1增益／改善折 | M2 MSE | M2增益／改善折 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 128 | 5.647046 | 5.815288 | -2.979%／1/10 | 5.996150 | -6.182%／1/10 |
| 512 | 5.166425 | 5.114235 | 1.010%／5/10 | 5.122045 | 0.859%／8/10 |
| 2048 | 4.658323 | 4.646307 | 0.258%／1/10 | 4.647177 | 0.239%／1/10 |

512至2048时，加性主参照的pooled MSE降低9.835%，M1、M2相对它的增益反而缩小；三个预算均未达到预定联合条件，也未支持稳定的教师特异性。当前证据支持在这些固定训练前缀下增加材料改善预测，不支持以教师先验的独特价值为由扩大研究。判定为INCONCLUSIVE_UNDER_BUDGET，不等于证明所有功能信号不存在。

后续优先分析加性选择波动、教师与protein的适配性及功能面板覆盖。余项方差集中有证据，但高方差窗口移除未带来实用增益；尚不能确定弱增益的主要原因。Study观测、原定模拟、完整调用及替代锚点敏感性仍未完成，保留为解释限制。暂不扩大教师、网络或完整模拟；3,506个封存材料的表型继续隔离。以上均为方法开发结果，不构成独立验证，后续修改须保留版本记录。

## ACR 来源与面板验收

此前取得的门户种子 BED 标注为 HML 未发表资源；固定 600 bp 预检最多形成 20 个多 SNP 非重叠窗口，不能达到 32 个要求，保留作来源预检，不用于本版面板。

本版正式外部来源采用 [LIS 的 Wm82.gnm4.atlas_ctACRs.Zhang_Schmitz_2024](https://data.legumeinfo.org/Glycine/max/sequence_feature/Wm82.gnm4.atlas_ctACRs.Zhang_Schmitz_2024/)，与 [GSE270392](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE270392)对应的五个种子发育阶段、52 个细胞类型 BED。全部 BED 通过官方 MD5 和 gzip 校验，MANIFEST、CHANGES 也通过 MD5；来源、字段及摘要见 `data/soybase/raw/acr/seed_ctacrs_manifest.json`。另保留五阶段官方计数矩阵作来源材料，不将其行名未经核验直接当成 BED。

辅助 Wm82.a4 FASTA 的 MD5/gzip 通过；其 README 当前镜像新增引用，已从官方元数据 Git 历史恢复与校验表匹配的版本。ACR README 的差异是官方提交修正了集合 identifier，同样保留校验匹配的历史原文及官方修正 commit。差异没有被忽略或覆盖，证据见 `a4_metadata_resolution.json`、`ctacrs_metadata_resolution.json`。额外下载的未列入参考校验表的现代 MANIFEST 不作为必需参考要求证据。ACR README 的 citation 字段含不相关引用，文献归属依据其 DOI/title、GEO 及作者仓库核验，不复制错误引用。

72,022 个候选窗中 68,859 个通过映射；其中 65,802 个无 SNP、3,021 个只有一个 SNP、36 个有至少两个 SNP。按配置中的固定 source-region-ID 哈希及非重叠规则选出 **35 个窗口**，31 个含两个 SNP、4 个含三个 SNP，均为正向匹配，达到目录覆盖门槛。面板及来源映射保存在处理目录 `seed_ctacrs_selected_windows.bed/tsv`，证据见 `runs/soybase_official_v2_acquisition/ctacrs_mapping_validation.json`。训练调用与教师功能信号分别记录于下文。

本版面板覆盖 74 个不同 SNP，芯片目录内单倍型序列上界为 156。已在 160 个实际外层／预算／内层训练场景核查缺失、未定相多杂合、训练调用率及多态性：所有场景均有 35 个达到 95% 调用有效性且至少两个通过训练 QC 的 SNP 的窗口，最低有效比例 98.96%。部分小预算场景仅 28 个窗具有至少两个多态 SNP；单态列仍按要求保留。该结果的范围是调用有效性。

映射、选择及训练调用有效性核查由 `preprocessing/regions.py` 实现，四个针对性测试覆盖次要比对歧义、SNP/BED 边界、序列不一致拒绝、固定哈希与不重叠及训练／测试调用隔离。新的 ACR 及窗口映射协议使用独立版本标识，输入验收版本为 v3，两核交互及置乱对照加入后使用实验v4；新增与M2匹配的MI3／MRPerm3使用实验v5。固定划分与输入文件保持不变。

## 教师接口与功能信号验收

教师采用官方基础模型 revision `f756c255cb76e9f538c3acec04acf4214ed03fb3` 和已配置适配器 revision，权重与官方 LFS SHA256 一致；完整适配器及分类头恢复逐参数核验。标签方向与无特殊 token 输入由指定版本的官方微调源码核验。批量 8 与单条推理曾出现约 4.02e-4 的分数漂移，相关结果保留为未通过证据。正式接口版本见配置 `teacher.inference_version`：固定每序列模型微批次 1，实际 156 种序列全部推理，并将 64 种倒序、以不同外部批次重复，最大原始 logits／分数差均为 0；峰值 GPU 分配约 1.03 GB，200,000 次调用按线性比例推算约 4.73 GPU 小时。

上述推算仅针对教师；回归的一外折成本测量见下文，完整合成矩阵的CPU／RAM安排尚未验证。

160 个固定训练场景中，最小中心化 A 块 RMS 为 0.3853，R 块为 0.07256，超过当前 `max(1e-8,10ε)` 阈值；分解恒等式最大绝对误差 8.9e-16。逐窗口可分辨 R 数量不同：128 上限场景 28–32 个，512 上限 30–33 个，2048 上限 32–35 个；完整外层训练 34–35 个。95% 调用有效性所要求的 35 个窗与这些非零信号窗数分别报告，该记录仅说明功能块信号可分辨，不包含预测增益。

## 实现、诊断及未通过事项

当前已实现训练侧QC／填补、可信单倍型、D/A/U/R、必做对照、EN／GBRT选参、指标与固定四内折及外层评价程序。MI3与MRPerm3已加入统一三核搜索和配对比较；同编号MRPerm与MRPerm3共用置乱余项核。

EN已使用同一训练分区内按l1比例分别由强到弱的正则路径。高维混合L1/L2候选在坐标迭代后仍未收敛时，改用同一损失函数的样本空间对偶求解；纯L1候选在逐步扩大的变量子集中进行坐标求解，每轮检查全部SNP的梯度与完整dual gap；只有达到原门槛才返回成功。保持配置中的总迭代上限，不跨折复用系数。v5的42项针对性测试通过，覆盖匹配搜索、原损失一致性、训练／测试统计隔离和组泄漏拒绝。该记录不代表合成功效验收。

主预算无表型诊断已完成 50 个训练场景，均保留 35 个可用窗口。R 的参与率有效秩（trace²／Frobenius 范数平方）约 1.23–1.43，无教师交互核约 9.65–13.94；训练余项特征的最大单窗方差占比为 81.5%–86.5%，前三窗合计为 98.6%–99.2%；这不是 protein 贡献或因果分解。可分辨信号集中在少数方向，不能把 35 个物理窗口解释成 35 个独立功能信号。独立输出在 `runs/`，不入 Git。

v5已完成固定主预算512、合成响应下的一外折全模型成本测量：四个内折和外层重拟合合计194.37秒，峰值内存5.95 GiB，未读取任何真实表型。54个实际比较流程均完成；M2、MI3及十个MRPerm3各搜索105个配置。输入、实现哈希、全部EN候选的收敛记录、选参和预测摘要见 `runs/soybase_official_funcprior_v5_profile_20261011T131126185449Z/`。
