# SoyBase 功能先验基因组预测项目任务书

项目：`fprior`，从 `at_pheno` 衍生的独立研究项目。任务版本：2026-10-11。实验版本与全部运行参数以[唯一配置](../configs/funcprior.toml)为准。

本任务书定义大豆实验的目标、数据、工作、交付和完成条件。[研究方案](研究方案.md)提供数学定义与解释边界，[验收规范](验收规范.md)提供通用输入输出要求、对照定义和数值要求；当前统计与实际验收结果见[验收记录](验收记录.md)。原拟南芥参考、物种范围和五折安排不直接套用 SoyBase，大豆适配以本任务书和配置为准。

## 一、研究目标与范围

在相同 SoyBase 样本、标记目录和隔离验证协议下，检验固定植物功能教师的先验是否改善大豆种子蛋白含量预测，回答：

1. 一阶功能协方差是否优于普通加性收缩和相同教师分数形成的对角注释加权？
2. 参考锚定的教师余项是否优于完整个人功能输出、普通单倍型核和局部非线性核？
3. 预测增量是否在不同训练样本预算、完整调用覆盖和参考锚点下保持方向一致？

首轮研究受限训练样本预算下的预测风险，SoyBase 全队列提供开发评价材料。训练预算、主预算和内外层折数从配置读取；全队列拟合须在首轮验收及计算预算通过后另立版本，不能替代小样本主比较。其他性状和独立外部材料验证属于后续版本；同队列的 oil 分析不构成独立材料验证。

实验属于功能先验的预测验证。核权重解释为预测验证选择，预测提升解释为本协议内的经验增量，不解释为遗传率、方差组分、因果调控、真实育种价值或普遍优势。

## 二、数据与划分

### 2.1 数据范围与输入要求

分型唯一来源为 SoySNP50K Song/Hyten 2015 的 Wm82.gnm2 官方发布 VCF，匹配参考为 Wm82.gnm2.DTC4（Wm82.a2.v1）。正式标记目录只纳入核染色体双等位 SNV，使用匹配 markerMap 核验 ID、染色体、位置及 REF。

本版范围是固定的 17,526 个合格标签与 VCF 交集材料，以及 41,346 个核染色体双等位 SNV。按既有固定清单使用 14,020 个开发材料、3,506 个封存材料；这些数字定义本版范围，其统计依据见[验收记录](验收记录.md)。旧 BiMSGP 矩阵、折号、论文配套模型和历史结果按来源材料保留，不作为本版分型、划分或预测结果。

原始来源存放在 `data/soybase/raw/`，预处理由本项目 `preprocessing/` 负责；算法读取 `preprocessing/processed/soybase_official_v2/` 中通过验收的产物。来源 manifest 应记录 URL、发布版本、校验和与完整性证据。匹配 FASTA、ACR BED、教师 manifest 及明确版本的样本划分文件为必填输入，缺失即停止真实训练，不以空清单、GWAS 峰或临时来源替代。

### 2.2 主性状与观测规则

主性状在查看本轮预测前固定为 `protein`，写入配置 `primary_trait_id`；该字段无默认值，缺失时仅做无表型验证并返回 `TARGET_UNSPECIFIED`。性状定义依据 GRIN 描述符 51016，为种子干重蛋白百分比。方法包括 NIR 与 Kjeldahl，结果应保留具体方法追溯，不把所有值统称为湿化学直接测定。

标签使用官方逐 Study 发布值。排除配置指定的 `SOYBEAN.DEVELOPER.DATA`（490512，仅由开发者提供）和 `SOYBEAN.GENERAL`（488001，无明确实验环境）；完整原始来源保留。汇总先对同一 accession、同一 Study 内的库存行取均值，再对不同 Study 等权取均值。标签不填补、不作尺度变换，不按材料数、基因型或预测效果加权。

accession 规范化仅移除空白，保留数字及字母后缀，不按常用名合并。标签表示已声明研究环境下官方发布值的平均，不代表单次原始实验测量；未说明的底层重复与仪器方法不作推断。历史单行导出不替代逐 Study 来源与汇总要求。

表型来源记录须保留材料、Study、库存、原始值、方法、单位及来源信息。仅从既定划分文件取得14,020个许可开发accession，按材料向USDA GRIN-Global查询protein观测；先检查配置指定的20个随机开发材料，页面完整且重算汇总与原开发标签一致后，再获取其余材料。全部获取和异常处理见[验收规范 §2.4](验收规范.md)。

每个许可材料都须有可追溯的处理结论，逐Study记录中不得含封存ID。原始全量表型、划分前全队列表和34个Study的全量HTML均不能重新解析；标签及划分不重新生成。来源变化记 `SOURCE_VERSION_DRIFT`；无法恢复完整历史观测记 `STUDY_AUDIT_UNAVAILABLE`，不能记为通过。带来源局限开展预测须在查看正式结果前另行明确授权并修订验收要求。


### 2.3 固定划分与访问隔离

官方新队列使用独立版本的开发／封存和近重复组划分，保留旧队列及父项目划分。分组依据原始调用，以配置规定的共同调用覆盖和一致率判断近重复；覆盖不足时，只有观察差异足以排除全目录近重复才分开，否则保守连接。连通组作为不可拆分单位。

开发／封存采用整组哈希前缀；开发外层折、各预算内层折及组哈希预算子集按配置和固定清单执行。同组材料不能跨开发／封存或验证折。样本划分确定后发现冲突，返回 `SPLIT_GROUP_CONFLICT` 并保留清单，不临时删材料、合并折或重新随机。

样本划分确定后只通过严格限制读取范围的接口读取许可开发行。读取前核验划分规定、封存禁止 ID、开发索引完整性，以及所请求行的身份和哈希；接口须直接定位许可行，不能先加载全表再过滤。原始全量表型、划分前全队列表、隔离封存标签和旧项目／父项目封存值禁止读取，不能为补齐观测核查而重新读取全量来源。最终一次封存评价须达到预注册判据后另行申请，本任务不授权启封。

## 三、需要完成的工作

### 3.1 分型编码与训练侧处理

以官方 VCF GT 转换 ALT 剂量 0/1/2；任一等位缺失时剂量为 NaN。独立保留逐等位调用、相位分隔符及完整调用掩码，部分缺失不能冒充参考等位，未定相剂量不能冒充已知双单倍型。

导出须核验材料和位点唯一性、列数、等位范围、全部原始 GT 类别及调用总数守恒。数组轴为 variant × sample，分别由 `variants.tsv` 与 `samples.tsv` 确定顺序；算法转换为 sample × variant 后按固定 ID 使用。

调用率、QC、缺失均值、可用窗口、中心化及核尺度均在每个实际内外层训练分区独立拟合，测试仅应用对应训练统计量。保留训练单态列，完全无调用列按 QC 剔除；全队列描述性统计不作为拟合参数。

### 3.2 外部 ACR 面板与可检验性

ACR 来源为 LIS 的 `Wm82.gnm4.atlas_ctACRs.Zhang_Schmitz_2024`，对应 GSE270392 的五个种子发育阶段、52 个细胞类型 BED。记录组织、材料、源参考及发布版本，按 manifest 验证文件完整性和来源归属。

从 0-based half-open BED 的源组装中心生成配置规定长度的窗口，排除边界不足和非 ACGT 序列，将完整窗口映射至匹配 VCF 的 Wm82.gnm2。两个组装上均要求 aligner 报告的唯一完整零编辑匹配、配置规定的 MAPQ、同一核染色体及独立 FASTA 序列一致性；保留次要比对作歧义排除。转移后不在目标组装重新取中点，MAPQ 不解释为穷尽全基因组的数学唯一性。

先按固定核染色体标记目录筛选多 SNP 候选，再按固定 source-region-ID 哈希选择非重叠窗口。报告零／单／多 SNP 候选数、映射失败原因、可接受窗口数及每窗 SNP 数。候选选择不读取表型、材料频率、基因型质量、教师分数或预测结果。候选不足时记录不可行原因，保持窗口长度与目录，不补入芯片外变异或 GWAS 峰。

本版使用已确定的35个窗口，实验期间不再调整。每个训练分区仅决定这些窗口的可用性，不补选；有效窗数与训练调用有效比例须达到配置门槛。调用有效、至少两个训练 QC SNP、至少两个多态 SNP以及教师可分辨信号的窗数分别报告。零／单 SNP 窗口不能作为检验跨位点协方差或教师余项的证据。

### 3.3 固定教师与可信序列

使用配置预注册的单一跨物种 PlantCAD2 ACR 教师。manifest 须记录并明确基础模型、LoRA／任务头、权重 revision 与哈希、tokenizer、标签映射、序列长度、精度、推理版本和代码 commit，并记录训练物种、组织与目标任务。大豆迁移效果属于待验假设，不能用 protein 微调教师或根据外层表现更换模型。

二分类功能输出为原始正负 logits 之差。参考、单变异及单倍型使用相同输入与推理配置，模型微批次按配置固定；输出不能改为最终概率或单独正类 logit。重复推理检查确定性、缓存及前向次数预算，按验收规范的数值噪声阈值关闭不可分辨功能块。

序列以匹配参考为背景，仅替换共同目录 SNP。可信纯合、已定相或可唯一确定的单杂合窗口按验收规范构造；缺失、多未定相杂合或已知未建模变异使样本—窗口无效。无效时原始 R 为零、原始 U=A，保留掩码，不以均值剂量制造序列。特征只能称为“芯片目录限定功能特征”，不称为完整个人基因组；未知芯片外变异及 ACR 源材料差异纳入适用边界。

教师的序列输出可按版本保存并复用；QC、填补、窗口有效性和中心化状态随训练分区重新拟合。教师、窗口、参考背景或搜索空间变化须另立版本，旧外层结果降级为开发证据。

### 3.4 数学核心与公平比较

实现[研究方案 §3–4](研究方案.md)定义的特征与多核回归，保持 Z=XD 和 U=Z+R。训练统计量、测试变换、归一化、数值精度与失败条件按[验收规范 §3–4](验收规范.md)执行。

| 要回答的问题 | 必做比较 |
| --- | --- |
| 一阶功能是否有用 | M0、EN、M1；强加性流程只在内层选择 |
| 是否需要跨位点协方差 | M1、MD、MP |
| 是否需要余项分解 | M2、M1、MU、MW、MWG |
| 是否超出普通局部表示 | M2、MHap、MLocal、MI3、MRPerm3、MI、MRPerm |
| 收益来自表征还是读出 | FU、FU-GBRT、MU |
| 是否由覆盖或锚点驱动 | 同材料／同窗口完整覆盖比较及替代锚点重拟合 |

对照精确定义及负对照重复见[验收规范 §4](验收规范.md)。MI3与MRPerm3保留M2的加性核和一阶功能核，仅替换第三核并共用三核搜索网格。MI 使用全部二阶／三阶单倍型共现；MRPerm 按窗口 SNP 数分层置乱完整教师系数向量，保持同窗口及同有效性掩码。所有模型使用相同输入信息、预算子集及外层测试材料。M1 阴性不能跳过最小面板 M2/MU/MW/MWG；必做基线失败或比较不完整时记录 `COMPARISON_INCOMPLETE`。

M1 是相关位点效应先验，不增加基因型非加性；M2 的分解改变先验，R 不等于生物上位性。无效窗口原始 R 置零可能引入覆盖信号，完整覆盖敏感性分析是余项结论的必要条件。后续若增加神经基线，学习率调整、早停和模型选择全部放在内层，按相同预算重训，不直接沿用历史测试集选优行为。

### 3.5 小样本嵌套评价与稳健性

每个外层训练 ID 范围内，按固定组哈希顺序形成配置规定的嵌套预算子集。保留完整组；下一组超预算时在此前缀停止，记录实际材料数与组数，不跳组凑额。无法形成规定内层划分时，该规模记不可用。

同一外层的小子集包含于大子集；预算外训练材料不参与该规模拟合。内层仅在预算子集中按固定组划分，逐内层重新拟合全部训练侧处理，以材料加权 pooled MSE 选参，再在预算子集重拟合，对固定外层材料输出一次固定预测。外层标签只供评价，不参与换窗、换教师、选预算、早停或调参。

主预算在预测前固定，不按学习曲线改到表现最好的规模。结果条件于固定抽样；若增加训练子集重抽样，另立敏感性版本，报告全部固定重复，不选择有利 seed。完成其他训练预算、完整覆盖、参考锚点及搜索预算敏感性分析；替代锚点依训练材料确定并完整重拟合，不选较好锚点替代主结果。

### 3.6 合成验收与计算预算

完成现有数值与训练隔离检查，以及原定720个合成机制数据集。另使用14,020个开发材料的真实基因型、既定35窗教师系数和有效性掩码，在主训练预算下完成六情景各200次、共1,200个合成表型实例；每个实例使用同一十外折、四内折，不读取真实protein。

生成规则与检测事件只维护于[配置 `pretraining`](../configs/funcprior.toml)，数学定义及通过条件见[验收规范 §5.3](验收规范.md)。先按指定实例测量资源和数值一致性，不按试测结果修改效应大小、教师权重分布或判据。分别报告技术检查与统计功效；低功效记 `POWER_LIMITED`，不能写成实现错误或完整功效验收通过。


先用无真实标签的结构数据或模拟教师测量最大训练预算构核、完整候选求解及预测成本，再推算全部外／内层和对照重复。教师 GPU 与回归 CPU／RAM 预算分开验收，分块读取、构核和预测保持原多核目标与精确单变异扫描。

超限时返回 `COMPUTE_BUDGET_EXCEEDED` 并停止扩展；不能减少测试材料、外层折、最强对照或只报告成功配置。内层 QC／缺失统计不同，不能直接切片全队列预处理核。矩阵自由迭代、低秩、Nyström 和搜索网格调整须另立版本，并核验原始—对偶及预测一致性。

## 四、执行与完成条件

### 4.1 验收顺序

| 工作 | 通过条件 |
| --- | --- |
| 来源与语义 | GT、缺失、REF/ALT、参考、标签方法和单位可追溯，输入映射与来源要求完整 |
| 划分与面板 | 独立版本清单固定，无未处理组冲突，目录覆盖、调用有效性与可检验性达标 |
| 实现与合成 | 针对性数值检查、原定 720 机制实验及真实稀疏实验技术检查通过，统计功效按预定标准单独报告 |
| 教师与资源 | manifest、原始 logits、重复推理、缓存、独立教师预算及全比较资源预算通过 |
| 主比较 | 全部必做对照在同一主预算完成，基线收敛、系统残差和配对预测达标 |
| 稳健性 | 其他预算、完整覆盖、锚点与搜索预算分析完成，结论不由这些因素单独驱动 |
| 开发决策 | 按预注册指标和科学对照明确继续、停止或预算下不确定，并保留解释边界 |

来源、实现和无表型检查可交错开展。真实输入未满足要求时仅做合成验证；正式训练前须满足所有前置条件。已经通过的检查仅在输入或相关实现改变时重跑。

### 4.2 正式训练前置要求

正式预测训练前，配置 `execution.pretraining_acceptance` 须指向与本实验、补充协议和样本划分一致的实际运行证据。逐Study材料范围与来源、原720个实例、附加1,200个实例、数学检查及功效报告须按[验收规范 §7](验收规范.md)逐项核验；只写JSON状态不足以通过。

来源核查缺失或不可恢复、技术检查失败、功效不足时，分别记录原因。探索性预测默认不允许；若接受来源局限或低功效，须在查看正式结果前另行明确授权，保留局限并降低结论强度。授权不替代实际技术检查，也不允许读取封存表型。

无表型诊断和合成响应成本测量不计为真实protein比较。新要求须先由验收接口实现，再进入正式评价；不能绕过现有 `_acceptance()`。


### 4.3 指标与去留判据

主指标为原量纲 pooled MSE，相对增益按相同材料上的配对误差计算；同时报告 MAE、PCC、校准斜率及 Q²。Q² 的参照均值来自各规模实际拟合的预算子集。单位依据来源要求，不凭数值范围猜测。

继续阈值、方向一致比例与 bootstrap 次数读取配置；本版十折按配置比例判断，不沿用原五折计数。以允许组为抽样单位，保持模型误差配对，区间只作为条件于固定子集和折外预测的开发描述，不包含重新抽样、拟合及搜索的不确定性。相关材料不作为独立重复，不用独立折 t 检验替代上述说明。

M1 的增量须接受 MD／MP 检验；若对角加权或置乱可解释收益，不主张功能协方差独特价值。M2 须超过 M1、完整 U 路线及普通局部／单倍型等必做对照，完整覆盖结论不反转，才保留余项特有贡献并申请扩大验证。

任务完成要求输入符合规定，比较、稳健性分析及可复核交付齐备，不以出现正结果为前提。允许负结果和明确的输入／可行性失败；区间过宽记 `INCONCLUSIVE_UNDER_BUDGET`，比较缺口记 `COMPARISON_INCOMPLETE`，这些状态不能写成完整预测比较验收通过。
