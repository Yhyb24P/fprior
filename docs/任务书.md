# SoyBase 功能先验基因组预测项目任务书

**项目：** fprior，从 `at_pheno` 衍生的独立项目；仅复用既有 Conda 环境与通用仓库管理原则。

**任务版本：** 2026-10-11，配置版本标识见 [`configs/funcprior.toml`](../configs/funcprior.toml)

**主性状：** `protein`，大豆种子蛋白含量

**实验性质：** 小样本功能先验的预测验证；不作因果机制或新模型原理主张

## 一、目标与任务边界

在同一 SoyBase 样本、标记目录和隔离验证协议下，检验固定植物功能教师提供的先验是否提高种子蛋白含量预测，并回答三个问题：

1. 一阶功能协方差是否优于普通加性收缩和相同教师分数形成的对角注释加权？
2. 参考锚定的教师余项是否优于完整个人功能输出、普通单倍型核和局部非线性核？
3. 预测增量是否在不同训练样本预算、完整调用覆盖和参考锚点下保持方向一致？

SoyBase 全队列用于提供开发评价材料，首轮研究对象是受限训练样本预算下的预测风险。训练规模、主规模、外层及内层折数均读取唯一配置；不以全队列训练结果替代小样本主比较。全量拟合只有在首轮验收及计算预算通过后才能另立版本开展。

本任务书负责大豆数据适配、执行顺序和交付条件；[研究方案](研究方案.md)负责数学定义与解释边界；[验收规范](验收规范.md)负责通用输入合同、模型对照和数值测试。研究方案中原拟南芥参考、物种范围及五折安排不直接套用 SoyBase；大豆任务采用本任务书与配置明确的安排，其余训练隔离、精确教师推理和对照要求继续保留。新增本文件是用户要求的项目执行合同，不另建阶段计划、状态页或收尾报告。

当前已取得并核验官方原始分型与匹配参考、全部 protein Study 来源及可达门槛的映射 ACR 面板；B 阶段第一批数学核心已通过合成单元验证（见 §八）。真实教师 logits 与无表型功能可行性已验收；模型训练和完整预测比较尚未完成。

### 2.2 主性状与观测规则

主性状仍为预测前固定的 `protein`，不按预测表现重新选择。[GRIN 描述符 51016](https://npgsweb.ars-grin.gov/gringlobal/descriptordetail?id=51016)定义为种子干重蛋白百分比。官方方法包括 NIR 与 Kjeldahl；[方法 494186](https://npgsweb.ars-grin.gov/gringlobal/method?id=494186)明确描述研磨后 FOSS 6500 NIR 扫描，不能把所有数值称为湿化学直接测定。

从 [SoyBase GRIN Data Explorer](https://legacy.soybase.org/grindata/)按 All GRIN Accessions → Chemical → Protein、保留完整范围导出的历史表，仅提供 accession、数值和 GRIN 链接。每材料只有一行不证明只存在一次测量或说明其聚合规则。在查明官方选择／汇总方式前，不将该表作为已验收训练标签；不任取观测、不通过全队列变换匹配分布、不填补标签。

现已取得并核验描述符列出的全部 34 个 Study 材料表和方法文档，共 23,501 条官方发布值、17,699 个规范化 accession，其中 5,646 个 accession 对应多条 Study 行。各表行数与官方描述符列表一致；逐 Study 原始 HTML、方法描述、行数和摘要在 `data/soybase/raw/phenotype/`。2009 Study 的 5,530 条记录已完整取得。

主分析观测规则在预测前固定于唯一配置：排除 `SOYBEAN.DEVELOPER.DATA`（490512，仅由开发者提供）与 `SOYBEAN.GENERAL`（488001，没有明确实验环境），完整原始来源仍保留。余下 23,330 条发布值，先在同一 accession、同一 Study 内对库存行取均值，再让不同 Study 等权取均值；不按材料数、预测效果或基因型加权，不填补、不做尺度变换。结果是已声明研究环境下官方发布值的平均，不是单次原始实验测量；未说明的底层重复汇总和仪器方法不作推断，方法文档作为独立追溯依据。

规范化仅移除 ID 空白，不改写数字或字母后缀，不按常用名合并。有效标签与 VCF 无歧义交集为 **17,526 个材料**，2,561 个 VCF 材料没有合格标签，49 个合格标签没有对应 VCF。标准原始记录 `phenotype_protein_raw.tsv`、方法文档摘要 `protein_methods.json` 与 `protein_cohort_prefreeze.tsv` 在处理目录；后者只用于授权的划分前来源重建，不能作为冻结后的开发读取入口。源隔离清单冻结后禁止重放全量表型解析，必须先生成严格隔离的开发输入。

`preprocessing/phenotypes.py` 实现逐 Study 解析、方法文档身份核验及上述固定汇总，不将文本库存号冒充数字 inventory ID，不把零 OBSERVATIONS 元数据解释为没有发布值。五项针对性测试通过；完整来源与对齐证据见 `runs/soybase_official_v2_acquisition/protein_source_validation.json`。

表型来源记录应包含 accession、descriptor、study、inventory（若有）、原始值、方法、单位、含水基准、选择／汇总、填补及变换规则。公开新队列的来源获取发生在新划分冻结前；冻结后，开发表型必须经严格隔离接口提供，封存表型禁止读取。旧项目及父项目封存值始终禁止访问。

## 三、输入适配与先决条件

### 3.1 编码、参考和缺失信息

官方 VCF 的 GT 是唯一编码依据，转换为 ALT 剂量 0/1/2，任一等位缺失时剂量为 NaN。逐等位调用和相位分隔符独立保留；`0/1` 与 `1/0` 剂量相同，但不能宣称具有可信相位。全调用与相位标志共同决定定相调用有效性；部分缺失不得伪装成参考等位。

`preprocessing/genotypes.py` 对全部原始记录统计 GT 类别，检查材料及位点唯一性、列数和等位范围，正式导出仅保留已核验核染色体双等位 SNV。数组轴顺序为 variant × sample，样本与位点顺序分别由 `samples.tsv`、`variants.tsv` 确定；不进行全队列 QC、频率筛选、填补或中心化。训练侧转换继续由 `DosageTransform` 在每个训练分区独立拟合。

划分前来源审计显示 11,925 个单 Study、5,601 个多 Study 材料；跨 Study 观测差异仍待仅限许可开发记录的隔离审计，不重放封存值、不修改已冻结汇总规则。

### 3.2 新版本隔离与划分

用户已要求为官方新材料队列建立独立、带版本标识的开发／封存及近重复组划分。这是新队列协议，旧 `soybase_protein.csv` 及父项目划分保持不变，不作为本版输入。官方观测规则和 ACR 可检验性核验后，先冻结新队列与划分，再验证教师及进入训练。

新划分按配置 `evaluation.partition` 冻结：共同调用覆盖至少 98%、调用一致率至少 99.5%，覆盖不足时仅在观察差异足以排除全目录近重复时分开，否则保守连接；连通组不可拆分。17,526 个材料形成 13,546 组，最大组 70 个；17 个低调用材料保留。按固定组哈希前缀选择最接近 20% 的整组封存，得到开发 14,020、封存 3,506，开发十折各 1,402 个材料。每个外层训练预算独立冻结四折内层；整组前缀遇超预算停止，128 上限的一折实际为 68 个材料，不跳组凑额。清单、合同和独立审计在处理目录，配置引用正式路径。真实教师及嵌套比较实现已验收至开发测试层面；开发 Study 审计和合成功效验收未完成，继续停止真实性状比较。开发十折仅作用于开发集，嵌套选参不接触封存值；满足预注册门槛后另行申请最终一次独立封存评价。

`io.load_development_phenotypes` 先核验冻结合同、封存禁止 ID 和开发索引完整性，再按许可 ID 的字节偏移仅读取所请求的开发行，并校验行身份和哈希；不打开原始表型来源、划分前全队列表或隔离封存标签。冻结后这些全量来源严禁重放；父项目业务流程不作为本项目运行依赖。

## 四、稀疏标记下的功能面板

### 4.1 必须先证明可检验性

官方 SNP 目录及参考匹配的种子 ACR 面板已核验，窗口覆盖基于新目录重新统计，不沿用旧矩阵的近邻计数。

对目录限定序列，一个有效窗口若没有 SNP，则 Z 和 R 均无信号；若仅有一个 SNP，按两条同源染色体功能输出相加的定义，对任何合法剂量都有 `U_raw=A`，故 `R_raw=0`。单 SNP 窗口的 `DDᵀ` 也没有窗口内跨位点项。不能用这种面板声称检验过协方差共享或教师余项。

本版因此在原参考窗口生成与非重叠哈希选择之前，增加**固定目录内多 SNP 条件**，阈值只读取配置的 `regions.min_catalog_snps`。此条件只使用已冻结核染色体目录和外部 ACR 坐标，不读取材料频率、基因型质量、protein、教师分数或预测结果。窗口、参考和选择规则的版本变更已经由 SoyBase 新实验标识区分。

完成参考与 ACR 映射后，报告候选窗中零/单/多 SNP 数、可接受非重叠窗口数、每窗 SNP 数及映射失败原因；再按固定哈希顺序选取。候选不足时如实报告，不扩大窗口长度、不加入芯片外变异、不改为 GWAS 峰，也不根据功能打分重新挑窗。各训练分区随后只决定已选窗口的可用性，不补选新的窗口。

### 4.2 ACR、教师与可信序列

ACR 必须来自外部大豆功能测量，记录组织、材料、参考和发布版本。此前取得的门户种子 BED 标注为 HML 未发表资源；固定 600 bp 预检最多形成 20 个多 SNP 非重叠窗口，不能达到 32 个要求，保留作来源预检，不用于本版面板。

本版正式外部来源采用 [LIS 的 Wm82.gnm4.atlas_ctACRs.Zhang_Schmitz_2024](https://data.legumeinfo.org/Glycine/max/sequence_feature/Wm82.gnm4.atlas_ctACRs.Zhang_Schmitz_2024/)，与 [GSE270392](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE270392)对应的五个种子发育阶段、52 个细胞类型 BED。全部 BED 通过官方 MD5 和 gzip 校验，MANIFEST、CHANGES 也通过 MD5；来源、字段及摘要见 `data/soybase/raw/acr/seed_ctacrs_manifest.json`。另保留五阶段官方计数矩阵作来源材料，不将其行名未经核验直接当成 BED。

辅助 Wm82.a4 FASTA 的 MD5/gzip 通过；其 README 当前镜像新增引用，已从官方元数据 Git 历史恢复与校验表匹配的版本。ACR README 的差异是官方提交修正了集合 identifier，同样保留校验匹配的历史原文及官方修正 commit。差异没有被忽略或覆盖，证据见 `a4_metadata_resolution.json`、`ctacrs_metadata_resolution.json`。额外下载的未列入参考校验表的现代 MANIFEST 不作为必需参考合同证据。ACR README 的 citation 字段含不相关引用，文献归属依据其 DOI/title、GEO 及作者仓库核验，不复制错误引用。

从官方 0-based half-open BED 的源组装中心生成固定 600 bp 窗口，去除边界及非 ACGT 序列，再将整个窗口映射到匹配 VCF 的 Wm82.gnm2。要求两个组装上均为 aligner 报告的唯一完整零编辑匹配、MAPQ 至少 60，保留次要比对用于歧义排除，匹配同一核染色体，并逐窗口独立核对 FASTA 序列。MAPQ 是工具报告的证据，不宣称穷尽全基因组的数学唯一性。完整源中心窗口转移后不再重新取中点，来源位置、组装、比对与窗口规则均保留版本。

72,022 个候选窗中 68,859 个通过映射；其中 65,802 个无 SNP、3,021 个只有一个 SNP、36 个有至少两个 SNP。按配置中的固定 source-region-ID 哈希及非重叠规则选出 **35 个窗口**，31 个含两个 SNP、4 个含三个 SNP，均为正向匹配，达到目录覆盖门槛。面板及来源映射保存在处理目录 `seed_ctacrs_selected_windows.bed/tsv`，证据见 `runs/soybase_official_v2_acquisition/ctacrs_mapping_validation.json`。训练调用有效性与教师功能块分别验收如下，不能仅据窗数宣称预测有效。

当前固定面板覆盖 74 个不同 SNP，芯片目录内单倍型序列上界为 156。已在 160 个实际外层／预算／内层训练场景审计缺失、未定相多杂合、训练调用率及多态性：所有场景均有 35 个达到 95% 调用有效性且至少两个通过训练 QC 的 SNP 的窗口，最低有效比例 98.96%。部分小预算场景仅 28 个窗具有至少两个多态 SNP；单态列仍按合同保留。该结果不证明教师功能信号或预测功效。原 8 SNP／窗合成设计须另加匹配真实 2–3 SNP 稀疏度的功效分析，不能替代真实面板验收。

映射、选择及训练调用有效性审计由 `preprocessing/regions.py` 实现，四个针对性测试覆盖次要比对歧义、SNP/BED 边界、序列不一致拒绝、固定哈希与不重叠及训练／测试调用隔离。新的 ACR 及窗口映射协议使用独立版本标识，输入验收版本为 v3，匹配交互及置乱对照加入后，实验版本由配置更新为 v4；冻结划分与输入文件不改写，旧源码及来源材料不冒充新外层实验结果。

教师使用配置预注册的单一跨物种 ACR 候选。[PlantCAD2 官方文档](https://raw.githubusercontent.com/plantcad/plantcad/main/docs/PlantCAD2-overview.md)提供该任务与权重接口；[官方推理源码](https://raw.githubusercontent.com/plantcad/plantcad/main/src/lora_fine_tune.py)显示分类输出取两类 logits 的 softmax。因此本任务读取原始正负 logits 之差，不能使用最终概率或只取正类 logit。

教师采用官方基础模型 revision `f756c255cb76e9f538c3acec04acf4214ed03fb3` 和已配置适配器 revision，权重与官方 LFS SHA256 一致；完整适配器及分类头恢复逐参数核验。标签方向与无特殊 token 输入由固定官方微调源码核验。批量 8 与单条推理曾出现约 4.02e-4 的分数漂移，相关结果保留为未通过证据，不用于功能信号。正式接口版本见配置 `teacher.inference_version`：固定每序列模型微批次 1，实际 156 种序列全部推理，并将 64 种倒序、以不同外部批次重复，最大原始 logits／分数差均为 0；峰值 GPU 分配约 1.03 GB，200,000 次调用线性投影约 4.73 GPU 小时。这不替代回归全比较 CPU／RAM 预算验收。

160 个冻结训练场景中，最小中心化 A 块 RMS 为 0.3853，R 块为 0.07256，超过当前 `max(1e-8,10ε)` 阈值；分解恒等式最大绝对误差 8.9e-16。逐窗口可分辨 R 数量不同：128 上限场景 28–32 个，512 上限 30–33 个，2048 上限 32–35 个；完整外层训练 34–35 个。95% 调用有效性所要求的 35 个窗与这些非零信号窗数分别报告，不按教师分数补选，也不把块非零解释为预测增益。


教师验收必须落实基础模型及 LoRA/任务头的完整版本、权重哈希、tokenizer、标签映射、序列长度、精度和代码 commit；只写适配器名称不足以冻结教师。记录其训练物种、组织和目标任务，大豆迁移效果属于待验假设。没有大豆专用 checkpoint 不自动禁止跨物种检验，但未经版本和接口核验不得推理，不能用 protein 微调教师或根据外层分数换模型。

窗口使用匹配参考的序列，仅替换共同目录内的 SNP。纯合调用或可唯一确定的单杂合窗口按验收规范处理；多个未定相杂合、缺失或已知未建模变异使该样本—窗口无效。未知芯片外变异不能假装不存在；结果只能称为“芯片目录限定功能特征”，不称为真实个人基因组或完整单倍型功能。ACR 源材料与当前材料不一致也须列入适用边界。

推理前先完成配置规定的重复 profiling，核对确定性、缓存、有效窗口和前向次数预算。推理成本未通过时停止扩大；只缓存冻结教师的序列输出，不缓存并复用全队列拟合的 QC、填补均值、窗口有效性或中心化状态。

## 五、算法实施与最小比较

### 5.1 必须保留的数学关系

令 D 为“位点 × 窗口”稀疏矩阵；以当前训练均值填补得到 Q，中心化得到 X。先构造 `A=QD`、原始完整功能 U 及 `R_raw=U_raw−A`，再统一训练中心化，使 `Z=XD`、`U=Z+R`。

各特征核按自身训练迹归一化，零方差或教师数值噪声块关闭。给定非负单纯形权重，使用 `K_w=Σ w_s K_s`，解 `(K_w+nρI)α=y−mean_train(y)`，测试核采用同一训练均值与尺度。候选网格、精度和残差上限只读取配置，不能在实现里再写一套默认值。

M1 相当于具有 `DDᵀ` 结构的相关位点效应先验，不增加基因型的非加性。M2 可重写为 X 与 U 的线性读出，分解改变的是先验；R 不等于生物上位性。无效窗口令**原始** R 为零，中心化后仍可能带覆盖信号，完整覆盖敏感性分析不能省略。

### 5.2 比较对象与能支持的结论

| 任务问题 | 必做模型 | 判断依据 |
| --- | --- | --- |
| 一阶功能是否有用 | M0、EN、M1 | M0/EN 的强加性选择只在内层完成 |
| 是否需要跨位点协方差 | MD、MP 与 M1 | 相同教师，分别去掉非对角项或置乱局部映射 |
| 是否需要余项分解 | M2、MU、MW、MWG | 分解先验与完整 U 的线性/非线性核路线比较 |
| 是否超出普通局部表示 | MHap、MLocal、MI、MRPerm 与 M2 | MI 使用全部二阶／三阶单倍型共现；MRPerm 按窗口 SNP 数分层置乱完整教师系数向量；同窗口、同有效性掩码 |
| 收益来自表征还是读出 | FU、FU-GBRT、MU | 相同 U，不增加额外组学或标签 |
| 结论是否由覆盖或锚点驱动 | 完整可信覆盖、替代锚点重拟合 | 所有模型在同一材料和窗口子集上配对评价 |

精确定义、负对照重复及并列规则按[验收规范 §4](验收规范.md)。M1 阴性不能作为跳过最小面板 M2/MU/MW/MWG 的依据；任何必做基线失败或比较未完成，均不能宣布新方法获胜。窗口、基因型和性能日志须证明各模型使用同一信息。

本地 BiMSGP/DeepGS/DNNGP/SoyDNGP 源码与权重是历史来源材料，不是新算法的功能教师，也不是本轮比较结果。`data/paper_soybase/src/bimsgp/r/mamba_r_folder_oil_3_bi_1.py` 中每 epoch 调用外层 testloader，利用测试 RMSE 更新 scheduler，并按测试 PCC 保存最佳模型；这些行为不能直接复用于公平评价。若后续增加神经基线，须将学习率调整、早停和模型选择全部移入内层，保持同样训练预算与外层材料，重训后再比较。

### 5.3 实现分工

| 现有模块 | 实施职责 |
| --- | --- |
| `io.py` | 显式来源合同、ID/顺序/参考校验、封存排除和只读开发输入 |
| `features.py` | 可信序列、Boolean 系数、局部交互计数与 D/A/U/R 恒等式 |
| `design.py` | 当前训练分区 QC、可用窗口、类别目录、全部核及匹配置乱对照 |
| `teacher.py` | 完整 manifest、冻结推理、原始 logits 接口和按序列/version 缓存 |
| `kernels.py` | 加性及全部对照核、训练归一化和测试交叉核；不生成 M×M 协方差 |
| `solver.py` | 网格、复用分解、数值残差、失败记录和统一并列规则 |
| `baselines.py` | 训练侧 EN 与功能读出对照、收敛检查 |

预处理与算法分开，入口及模块拆分以实际职责为依据。先实现已有接口，再按验收需求补测试；不为一次运行增加常驻脚本。不得把尚未完成的实验或未通过的验收写成已具备能力。

## 六、划分、训练预算与防泄漏

### 6.1 冻结新官方队列的分组划分

本版以新官方材料及通过验收的 protein 观测交集确定队列，先依据原始身份、重复来源及可信基因型建立近重复组，冻结开发／封存和开发集十折及内层清单。分组规则、阈值和封存比例必须在预测前明确并写入唯一配置，不能直接照搬拟南芥阈值。

同组材料不得跨开发／封存或验证折。划分冻结后发现冲突时返回 `SPLIT_GROUP_CONFLICT` 并保留清单，不临时删材料、合并折或重新随机。旧 BiMSGP 折号只作历史来源保留，不套用新材料队列。

### 6.2 小样本嵌套评价

在每个外层训练 ID 范围内，按不依赖表型的固定 group 哈希顺序，形成配置规定的嵌套训练预算子集；每组完整保留，不将同组拆分以凑齐材料数。若下一完整组超过上限则在此前缀停止，记录实际训练样本数和组数；无法形成所需内层划分时该规模不可用，不临时放宽规则。

同一外层下，小规模子集包含于较大规模，所有模型共享子集和全部外层测试 ID；预算外的外层训练材料不参与该规模 QC、填补、窗口有效性、中心化或选参。整个可用队列的均值、频率和描述性统计均不作为拟合参数。

内层只在该外层的预算子集中按组建立冻结划分，所有训练侧预处理在每个内层训练部分重新拟合。内层 pooled MSE 选择每族配置，随后在对应预算子集重拟合，并对固定外层测试材料输出一次冻结预测。外层 y 不用于换窗、换教师、调参、选预算、早停或选择部署族。

首轮各规模使用一套预先冻结的组哈希顺序；其结果条件于该抽样，不冒充已经包含训练子集重抽样的不确定性。需要重复抽样时，在主结果之外另立敏感性版本，完整报告固定重复，不选择有利 seed。

protein 为唯一主要终点；不得根据学习曲线把主预算改到表现最好的规模。oil 的后续分析重新冻结其目标与配置，保持同队列比较的局限，不作为独立材料验证。

## 七、计算可行性与求解范围

以冻结官方队列 17,526 个材料计，单个 float64 方形核约 2.29 GiB。实际开发队列为 14,020 个材料，但主比较按冻结小预算运行；多个核、分解与交叉核会继续增加峰值内存；必须按最终尺寸及实测成本验收。

首轮按配置的小样本训练预算运行，教师保持精确单变异扫描，求解保持原多核目标；分块读取剂量与构建训练核、交叉核，必要时分块输出测试预测。不同内层 QC 或缺失统计不能直接切片一个全队列预处理核。

先在无真实标签的结构数据或 mock teacher 上测量最大训练预算的构核、完整候选求解和预测时间，再推算实际外/内层及对照重复的总成本。教师 GPU 时间与回归 CPU 时间分开记录，配置的教师预算不代表回归也已通过预算。

超出预算时返回 `COMPUTE_BUDGET_EXCEEDED`，停止扩展；不得暗中减少测试材料、挑少量外层折、删掉最强对照或仅报告成功配置。矩阵自由迭代、低秩近似、Nyström 或不同搜索网格均不在当前首轮默认范围；需要采用时先评估是否改变数值或统计目标，立新版本并通过原始—对偶及预测一致性核验。

当前已实现训练侧 QC／填补、可信单倍型、D/A/U/R、全部必做对照、EN／GBRT 选参、指标与冻结四内折／外层编排；合成集成测试覆盖端到端模型目录、测试统计隔离与组泄漏拒绝。尚未执行原定 720 组合成机制验收及匹配实际 2–3 SNP 窗口的功效分析，不能标记 B 阶段整体通过。

主预算无表型诊断已完成 50 个训练场景，均保留 35 个可用窗口。R 的参与率有效秩（trace²／Frobenius 范数平方）约 1.23–1.43，无教师交互核约 9.65–13.94；训练余项特征的最大单窗方差占比为 81.5%–86.5%，前三窗合计为 98.6%–99.2%；这不是 protein 贡献或因果分解。可分辨信号集中在少数方向，不能把 35 个物理窗口解释成 35 个独立功能信号。独立输出在 `runs/`，不入 Git。

真实基因型、冻结主预算及合成响应的全比较成本试运行，在约 656 秒后因 ElasticNet 未收敛停止：dual gap 为 1.84e-5，允许上限为 9.43e-7；状态为 `COMPARISON_INCOMPLETE`，不是完整比较总成本，也不是 protein 结果。先前线程池未受限制的试运行已标记无效；重新限制全部数值库为 4 线程后仍发生上述失败。不得删除失败候选、放宽容差或借此宣称模型胜出。

当前先完成主预算比较开发与 P0 审计，再开展合成功效和正式十折比较；不扩展教师、原始数据或网络。开发逐 Study 安全记录尚缺失：现有汇总标签不能重建材料内跨 Study 差异，不读取冻结前全队列表或封存值来补建。标签规则保持不变。

`evaluate` 在读取任何标签前，要求配置 `execution.pretraining_acceptance` 指向 JSON 验收记录：`experiment_version` 等于当前配置；`partition_manifest_sha256` 匹配冻结清单；`study_audit.status=PASSED` 且 `development_only=true`；`synthetic_original.status=PASSED` 且 `datasets=720`；`synthetic_sparse.status=PASSED`。当前记录缺失，返回 `PRETRAINING_ACCEPTANCE_MISSING`。该门槛不授权封存评价。`diagnose` 不读标签；`profile` 使用真实主预算基因型与固定合成响应，完整四内折及一次外层成本不称为真实十折结果。调用方式统一见 [README](../README.md)。

## 九、指标、交付和停止规则

主指标为原始记录尺度的 pooled MSE；配对相对增益以同一材料上的误差计算。补充报告 MAE、PCC、校准斜率及相对于各自外层训练均值的 Q²。这里的训练均值来自该规模实际拟合的预算子集，不是全部外层训练 ID。protein 单位核实后才标注百分数或百分点，不能仅凭范围填写量纲。

主继续阈值、方向一致比例、bootstrap 次数均按配置读取；本版采用开发集组约束十折，方向判据按配置比例转换，不能沿用原五折计数。bootstrap 以允许分组为抽样单位并保持模型误差配对，只作条件于冻结训练子集与折外预测的开发描述区间，不包括重新选子集、拟合和搜索的不确定性。相关材料不能作为独立重复；不使用独立折 t 检验替代这一说明。

预测提升必须同时接受 MD/MP、完整 U、局部及单倍型对照的检验。若 M1 的增量被对角加权解释，不主张功能协方差独特价值；若 M2 未超过完整 U 或普通局部模型，不保留余项分解为核心贡献。未达到工程阈值不证明普遍无效；区间过宽记 `INCONCLUSIVE_UNDER_BUDGET`，输入、成本及比较缺口分别报告。

交付沿用[验收规范 §2.3](验收规范.md)的配置、来源、划分、QC、功能有效性、内层分数、配置选择、逐材料预测、核诊断、指标、耗时和状态文件。新增字段须能区分实验版本、训练预算、实际训练材料数、分组协议和源文件摘要。每一条预测可追溯实际训练 ID、目录、窗口和教师版本；失败不能用空文件或成功标记掩盖。

最终允许的结论是：在本地芯片目录、指定功能教师、protein 主性状和小样本验证协议内，功能先验有或没有支持继续研究的预测增量。不能据此声称改善真实育种价值、发现因果调控或获得普遍优势。全队列规模实验、其他性状和独立外部材料属于后续版本，不在本轮完成声明之内。
